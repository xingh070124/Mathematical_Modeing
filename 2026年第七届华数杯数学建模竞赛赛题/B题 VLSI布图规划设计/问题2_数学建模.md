# 问题2 数学建模：固定正方形轮廓内总 HPWL 最小的模块摆放

## 一、问题重述

芯片轮廓为**固定正方形**，边长由公式 $L=w_f=h_f=\sqrt{A(1+d)}$ 确定，死区比例 $d=0.15$。给定 $n$ 个矩形 HardBlock（尺寸 $(w_i,h_i)$ 已知，允许 90° 旋转，引脚位于几何中心）与 $m$ 个固定 Terminal（坐标由 `.pl` 文件锁定，仅参与线长计算），以及线网集合 $\mathcal{N}$。确定每个模块的位置与方向，使**所有线网的半周长线长（HPWL）之和最小**，同时满足**模块互不重叠、不超出正方形轮廓**的约束。需对 n100、n200、n300 三组数据独立求解，输出总连线长度与摆放可视化。

与问题1的本质区别：① 轮廓由"可自由优化的变量"变为"固定的约束"（空白从目标退化为约束）；② 目标由"面积最小"变为"总 HPWL 最小"；③ 引入线网与固定 Terminal，模块被"拉向"芯片内部 Terminal 所在的内框（见性质5），与不重叠约束形成对抗。

## 二、模型假设

1. 模块为刚体矩形，仅可平移与 90° 旋转（旋转即交换宽高）；
2. 模块间不允许重叠，边界允许贴合（共边/共点）；
3. 芯片轮廓为固定正方形 $[0,L]\times[0,L]$，边长按公式(1)取 $L=\sqrt{A(1+d)}$，$d=0.15$；
4. **Terminal 不占面积**：不参与面积统计、重叠约束与边界约束，允许与模块坐标点重叠；仅以固定坐标作为引脚参与 HPWL 计算；
5. 每个模块的所有引脚（本模型中为单一引脚）位于模块几何中心，坐标随摆放位置变化；
6. 线网线长以引脚包围矩形的**半周长**（HPWL）估算，与引脚内部实际连线方式无关。

## 三、符号说明

| 符号 | 含义 |
|---|---|
| $\mathcal{B}=\{1,\dots,n\}$ | HardBlock 集合（n100: $n=100$；n200: $200$；n300: $300$） |
| $\mathcal{T}$ | Terminal 集合（n100: $334$；n200: $564$；n300: $569$） |
| $\mathcal{N}$ | 线网集合（n100: $885$；n200: $1585$；n300: $1893$） |
| $\mathcal{P}_k$ | 线网 $k$ 的引脚集合（含模块中心与 Terminal 固定坐标） |
| $w_i,h_i$ | 模块 $i$ 原始宽、高 |
| $r_i\in\{0,1\}$ | 模块 $i$ 是否旋转 90° |
| $\hat w_i,\hat h_i$ | 旋转后实际宽、高 |
| $(x_i,y_i)$ | 模块 $i$ 左下角坐标 |
| $c_i=\big(x_i+\hat w_i/2,\ y_i+\hat h_i/2\big)$ | 模块 $i$ 中心（引脚）坐标 |
| $(X_t,Y_t)$ | Terminal $t$ 的固定坐标 |
| $A=\sum_i w_ih_i$ | 模块总面积（常数） |
| $d$ | 死区比例，$d=0.15$ |
| $L=\sqrt{A(1+d)}$ | 正方形芯片边长 |
| $\mathrm{HPWL}_k$ | 线网 $k$ 的半周长线长 |
| $\gamma$ | 越界罚函数权重（自适应） |
| $X_k^{\max},X_k^{\min}$ | 线网 $k$ 引脚横坐标最大值/最小值（辅助变量） |

## 四、决策变量与约束

**旋转尺寸变换**
$$\hat w_i=(1-r_i)w_i+r_ih_i,\qquad \hat h_i=r_iw_i+(1-r_i)h_i$$

**非重叠约束**（对任意 $i<j$，四析取其一）
$$(x_i+\hat w_i\le x_j)\lor(x_j+\hat w_j\le x_i)\lor(y_i+\hat h_i\le y_j)\lor(y_j+\hat h_j\le y_i)\tag{C1}$$

**固定轮廓边界约束**（区别于问题1：$W,H$ 不再是决策量）
$$0\le x_i,\quad x_i+\hat w_i\le L,\quad 0\le y_i,\quad y_i+\hat h_i\le L,\quad \forall i\in\mathcal{B}\tag{C2}$$

**MILP 等价形式**（供精确求解器）：大 $M$ 法线性化 (C1)，引入 $z_{ij}\in\{0,1\}^4$：
$$x_i+\hat w_i\le x_j+M(1-z_{ij}^1),\quad x_j+\hat w_j\le x_i+M(1-z_{ij}^2),$$
$$y_i+\hat h_i\le y_j+M(1-z_{ij}^3),\quad y_j+\hat h_j\le y_i+M(1-z_{ij}^4),\quad \sum_{k=1}^4 z_{ij}^k\ge1$$

## 五、目标函数：总 HPWL

对线网 $k$，引脚坐标集 $\{(X_p,Y_p)\}_{p\in\mathcal{P}_k}$ 中，模块引脚取中心 $c_i$、Terminal 引脚取固定坐标 $(X_t,Y_t)$，则
$$\mathrm{HPWL}_k=(X_k^{\max}-X_k^{\min})+(Y_k^{\max}-Y_k^{\min})$$
总目标
$$\min_{x,y,r}\ \sum_{k\in\mathcal{N}}\mathrm{HPWL}_k\tag{O2}$$

**MILP 线性化**：对每条线网引入辅助变量 $X_k^{\max}\ge X_p,\ X_k^{\min}\le X_p$（$y$ 同理），在最小化目标下自动取紧，可写成标准 MILP 供精确求解器使用。

**工程约定**：求解时取 $\hat L=\lceil L\rceil$（n100: 455；n200: 450；n300: 561）作为轮廓边长，以兼容整数坐标表示；$\lceil L\rceil-L\le1$，相对增大约 0.2%，远小于死区比例，对结果影响可忽略。

## 六、理论性质

**性质1（NP-hard）**：固定轮廓布图规划（fixed-outline floorplanning）包含二维装箱与分区问题为特例，故为 NP-hard（Adya & Markov, 2003）。$n=100\sim300$ 规模下精确算法（MILP/CP）无法在时限内闭合，需启发式为主。

**性质2（目标函数的凸分片线性结构）**：$\mathrm{HPWL}_k$ 关于模块中心坐标是**凸、分片线性**的函数（$\max$ 与 $-\min$ 均为凸函数），总和 $\sum_k\mathrm{HPWL}_k$ 亦然。凸性带来两个直接推论：① 无重叠约束下的"解析松弛"问题（见性质3）是凸优化，可高效求解并给出全局下界；② 在固定相对几何关系（packing 模式）下，最优位置可由坐标下降/中位数更新求得。

**性质3（松弛下界）**：去掉非重叠约束 (C1) 后得到**凸松弛问题**
$$\mathrm{HPWL}_{lb}=\min_{x,y,r}\ \sum_k\mathrm{HPWL}_k\quad \text{s.t.}\ \text{(C2)}$$
由于约束集合放宽，$\mathrm{HPWL}_{lb}$ 是原问题最优值的**全局下界**。该问题对 $x$、$y$ 可分离：对单个模块 $i$ 的横坐标 $x_i$，其贡献为若干 hinge 函数 $\max(0,\ x_i-h,\ \ell-x_i)$ 之和（$[\ell,h]$ 为相连线网中其它引脚的范围），最优值在该组断点的**加权中位数**处取得，坐标下降可高效收敛（实测值见第七节）。

**性质4（与问题1的整数值/压缩性质差异）**：问题1的"向左向下压缩保持最优性"依赖面积目标推动模块贴紧边界；问题2中 HPWL 目标会把模块**主动拉向所连 Terminal 的方向**，刻意留白可能最优，故压缩不保最优性，问题1的整数性引理不直接适用。此时应依赖性质2的凸结构：由于模块尺寸与 Terminal 坐标均为整数，且 $\hat L-L\le1$，存在各模块边界坐标落在"事件点"（若干模块宽高与 Terminal 坐标的整数组合）附近的近优解；实际求解中 B\*-树表示保证整数坐标，误差被限制在 $\hat L$ 取整范围内。

**性质5（Terminal 引力与可行性张力）**：实测三组数据的 Terminal 全部位于芯片内部一个 $[0,X_{\max}]\times[0,Y_{\max}]$ 的矩形边框上（n100: $X_{\max}=444$；n200: 438；n300: 548），四边各约占 25%，**不在芯片轮廓 $\lceil L\rceil$ 边界上**（距边界约 11/12/13 单位）。平均线网度仅 2.1–2.3（多为"1 个 Terminal + 1~2 个模块"或模块对）；每模块平均参与约 15 条线网，其中连接 Terminal 的约 4.5 条（仅占线网的 30~38%）。这意味着模块被 Terminal 线网拉向边界内框，与"模块不超出轮廓 + 互不重叠"形成**对抗张力**——模块既想贴近 Terminal 内框/其他模块，又必须在 $L\times L$ 内互不侵犯，这正是本问优化的难点与解质量的核心。

## 八、模型评价与扩展

- **优点**：HPWL 目标可精确线性化为 MILP，且有天然凸松弛给出**可证明的全局下界**；Terminal 不占面积、仅贡献 HPWL 的建模忠实于题意；B\*-树表示将 (C1) 从搜索中剔除，仅以罚函数处理 (C2)，搜索空间小。
- **局限**：大 $M$ 形式松弛质量差，仅适合极小规模精确求解；B\*-树只表示"左下压缩类"packing，无法表达刻意留白在内部的最优解（本数据下影响有限）；固定轮廓与整数坐标约定存在 ≤1 的取整偏差。
- **扩展**：自适应罚权重 $\gamma$（Chen-Chang）动态平衡可行性与 HPWL；终端引力/关键模块邻域移动（slack 思想轻量化）；"解析松弛放置 → 合法化修复"两阶段（PeF 范式）；与问题3衔接时只需将 $L$ 改为可变并做可行性夹逼搜索，模型主线不变（L4 开关配置）。
