## 一、通用提示词（AI 绘图工具可直接使用）

请生成一张**中文学术论文风格的 VLSI 布图规划"四层实施框架"流程示意图**，横版，构图自上而下分为 4 个层次，风格与问题一/二框架图保持一致（各层不同底色、实线箭头深灰、反馈箭头红色虚线），文字清晰、层级用方框和箭头表示。**重点突出中间的双证书夹逼回路（二分 + 可行/不可行证书）**。具体结构如下：

### 第4层（最上层，向下发出"Q3配置下发"箭头）
**第4层 场景适配接口层**：统一模型 + 开关配置
- 形状=矩形；旋转={0°,90°}
- 轮廓=搜索(L*)；目标=最小死区比例 d*
- 可行性判定：线网=不启用（HPWL 更新阶段启用）

向下箭头标注：**问题配置下发（Q3）**

### 第1层（第2行）
**第1层 多源初解生成池（紧凑装箱）**
- ① Skyline/BL 多规则（面积/长边/周长降序）
- ② HSA 树式贪心 + LFF 策略
- ③ 随机排列 + 随机预选 90° 旋转
→ 多样性粗筛 → K′ 个初解

向下箭头标注：**K′ 个紧凑初解**

### 第2层（第3行，核心）
**第2层 整数二分 + 可行性双证书**
- 二分区间：[L_lb, L_ub]，L = ⌊(L_lb+L_ub)/2⌋
- **可行证书**（启发式）：Skyline-ILS / B*-树-SA 装下全部模块 → L_ub ← L
- **不可行证书**（CP-SAT）：NoOverlap2D 证明无解 → L_lb ← L+1
- 未知：启发式失败且 CP-SAT 超时 → 维持区间继续二分

向下箭头标注：**可行/不可行证书**；左侧向上箭头标注：**gap / 下界反馈**

### 第3层（最下层）
**第3层 双向反馈定界校验层**
- 反向（搜索→定界）：可行布局 = **可行证书**，d* ≤ L²/A−1（上界）
- 正向（定界→搜索）：CP-SAT **不可行证明** → 下界上升；gap = (L_ub²−L_lb²)/A → 回馈第2层
- 输出夹逼区间 [L_lb, L_ub]，取 L* = L_ub，d* = (L*)²/A − 1

### 附加流程（右侧用虚线框或侧注标出）
**第二阶段（衔接问题二）**：在 L* 下复用问题二模型（B*-树-SA 增量 HPWL + 终端引力移动 / Skyline-ILS/SA）更新总 HPWL 与模块摆放可视化。

### 连接关系（务必画出）
- L4 → L1：Q3 配置下发
- L1 → L2：K′ 个紧凑初解
- L2 → L3：可行/不可行证书（可行为实线、不可行为虚线）
- L3 → L2：**红色虚线**回传 gap / 下界（双向反馈，突出"夹逼闭环"）
- L2 内部：**二分循环自环箭头**（L_ub/L_lb 交替收缩），标注"整数二分"

## 二、结构化内容清单（供手工复刻 / draw.io / PPT）

| 层 | 框标题 | 框内要点 |
|---|---|---|
| L4 | 场景适配接口层 | 形状=矩形 · 旋转={0°,90°} · 轮廓=搜索(L*) · 目标=最小d* · 可行性判定线网不启用 |
| L1 | 多源初解生成池 | 紧凑装箱：Skyline/BL多规则 · HSA · LFF · 随机+90°旋转 → 多样性粗筛 → K′个 |
| L2 | 整数二分 + 可行性双证书 | 二分[L_lb,L_ub]；可行证书=启发式装下全部（Skyline-ILS/B*-树-SA）→上界收缩；不可行证书=CP-SAT证明无解→下界上升；未知→维持 |
| L3 | 双向反馈定界校验层 | 可行布局=可行证书(上界) · CP-SAT不可行证明(下界) · gap=(L_ub²−L_lb²)/A 反馈 |
| 附 | 第二阶段（衔接Q2） | 在 L* 下复用问题二模型更新总HPWL与可视化 |

**数据流标注**：L4→L1 "Q3配置下发"；L1→L2 "K′ 个紧凑初解"；L2→L3 "可行/不可行证书"；L3→L2 "gap/下界反馈"（红色虚线）；L2 内部"整数二分自环"。

**关键数字（可标注）**：下界 $L_{lb}=\max(\lceil\sqrt A\rceil,\max_i\max(w_i,h_i))$；上界起点 $L_{ub}=\lceil\sqrt{1.15A}\rceil$；$d^*=(L^*)^2/A-1$。

**样式建议（与前两问一致）**：方框圆角 3–5mm，黑体/宋体 10.5pt，层标题加粗 12pt；四层同色系（蓝/青/灰）深浅区分；二分自环与双证书用橙色突出；反馈箭头红色虚线并加"gap"字样；画布白底。
