## 一、通用提示词（AI 绘图工具可直接使用）

请生成一张**中文学术论文风格的 VLSI 布图规划"四层实施框架"流程示意图**，横版，构图自上而下分为 4 个层次，要求风格清爽、配色统一（建议各层用不同底色，箭头为深灰色实线，反馈箭头为红色虚线），文字清晰、层级用方框和箭头表示。具体结构如下：

### 第4层（最上层，作为总开关，向下发出"Q2配置"箭头）
**第4层 场景适配接口层**：统一模型 + 开关配置
- 形状=矩形；旋转={0°,90°}
- 轮廓=固定(⌈L⌉)；目标=总HPWL
- 约束=无重叠/边界；线网=启用

向下箭头标注：**问题配置下发（Q2）**

### 第1层（第2行）
**第1层 多源初解生成池（终端感知）**
- ① 树式贪心（HSA，含线网度项）
- ② Terminal 锚点贪心（按相连引脚几何中心分簇装配）
- ③ Skyline/BL 多规则（固定 L×L 框，越界延后）
- ④ 随机/混合（多样性保底）
→ 多样性粗筛 → K′ 个初解

向下箭头标注：**K′ 个初始解（并行分发）**

### 第2层（第3行）
**第2层 并行元启发优化层**
- 主算法：B*-树 + 快速模拟退火（增量 HPWL，Op1~Op5，自适应罚 γ）
- 对照算法：序列对 + 自适应遗传（SP+AGA）
- 多起点轨迹 + 精英池 + 强扰动重启

向下箭头标注：**候选解（可行证书·HPWL 上界）**；左侧向上箭头标注：**gap / 下界反馈**

### 第3层（最下层）
**第3层 双向反馈定界校验层**
- 反向（搜索→定界）：可行布局 = 可行证书，总 HPWL 上界
- 正向（定界→搜索）：凸松弛下界 HPWL_lb（中位数坐标下降）+ CP-SAT 子集验证
- gap = (HPWL_ub − HPWL_lb)/HPWL_lb → 回馈第2层判断是否扰动重启

### 连接关系（务必画出）
- L4 → L1：问题配置下发（Q2）
- L1 → L2：K′ 个初解并行分发
- L2 → L3：候选解（上界证书）
- L3 → L2：**红色虚线**回传 gap / 下界（双向反馈，突出"闭环"）
- 各层之间用粗实线箭头，整体呈现"自上而下落数据、自下而上反馈定界"的闭环结构
