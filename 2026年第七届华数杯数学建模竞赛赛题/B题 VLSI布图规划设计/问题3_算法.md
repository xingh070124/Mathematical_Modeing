# 问题3 算法设计：最小死区比例（双证书整数二分 + 可行性夹逼）

配套建模见《问题3_数学建模.md》。总体策略：**沿用问题一/二的四层求解框架**，仅在 L4 场景适配层把配置切到 Q3（`shape=rect, rotation=C4, outline=search(L*), objective=min_L, nets=False`），并针对"最小轮廓可行性"做方法优化：

> **L1 多源初解生成（紧凑装箱，复用 Q1）→ L2 整数二分 + 可行性双证书（Skyline-ILS/B\*-树-SA 可行 · CP-SAT 不可行）→ L3 双向反馈夹逼 → 第二阶段在 L\* 下更新 HPWL（复用 Q2）**

---

## 一、L1 多源初解生成池（复用 Q1，面向紧凑装箱）

直接复用问题1的四类初解机制，目标从"面积最小"改为"在给定 $L$ 下装下全部模块（溢出最小）"：
- 面积降序 / 长边降序 / 周长降序 / 最小间隙 / 随机排序；
- HSA 树式贪心（$V_i=\lambda_1\frac{h_iw_i}{L^2}+\lambda_2\frac{h_i+w_i}{2L}$）；
- LFF 策略（$|w-h|$ 大者先放）与随机预选 90° 旋转；
- 多样性粗筛：按"占用率 + 结构差异"保留 $K'$ 个代表初解，供 L2 各候选 $L$ 的可行性判定使用。

---

## 二、L2 主算法：整数二分 + 可行性双证书

利用**可行性关于 $L$ 单调**（建模文档性质2），在整数域上二分：

```
L_lb = max(⌈√A⌉, max_i max(w_i,h_i))          # 理论下界
L_ub = ⌈√(A(1+0.15))⌉                          # d=0.15 已知可行（问题2）
while L_ub - L_lb > 0:
    L = (L_lb + L_ub) // 2
    status = Feasible(L)                        # 三态：可行/不可行/未知
    if status == 可行:    L_ub = L              # 可行证书 → 上界收缩
    elif status == 不可行: L_lb = L + 1         # 不可行证书 → 下界上升
    else:                 # 未知：启发式失败且 CP-SAT 超时，维持区间，二分继续
        pass
输出: L* = L_ub（附可行布局证书）,  d* = (L*)²/A - 1
```

**Feasible(L) 三态 oracle**：
- **可行证书**：任一启发式找到无重叠摆放 → 返回（可行，布局）；
- **不可行证书**：CP-SAT `NoOverlap2D` 在时限内证明无解 → 返回不可行；
- **未知**：启发式失败且 CP-SAT 超时 → 不误判，区间维持，二分继续向可行方向推进。

## 三、可行性 oracle 具体实现（基于 Q1/Q2 方法优化）

### 3.1 Skyline/BL 多启动 + ILS（主 oracle，Q1 方法）
- 以固定框 $(L,L)$ 调用问题1的 Skyline 装箱引擎（`pack_skyline(..., box=(L,L), auto_rotate=True)`），判定是否装下全部模块；
- 多启动：不同排序规则 + 随机顺序 + 随机旋转并行尝试；
- ILS：随机抽 $k$ 个模块重插 / 交换 / 翻转旋转，Metropolis 接受，目标 = 溢出量最小化（溢出 $=0$ 即可行）。

### 3.2 B\*-树-快速模拟退火（精调 oracle，Q2 方法）
- 去掉 Q2 的 HPWL 项，代价仅含越界罚：$\mathrm{cost}=\gamma\cdot\sum_i\mathrm{overflow}_i$，表示内建无重叠；
- 自适应罚 $\gamma$：可行解占比低时增大 $\gamma$ 强制回界，持续可行时减小（Chen-Chang）；
- 温度重启 + 多起点精英池，逼近可行性边界时尤其有效。

### 3.3 增量收缩 warm start（新优化）
- 从大到小扫描/二分收敛过程中，把上一可行 $L$ 的解（放置顺序 + 旋转）**原样作为下一更小 $L$ 的初始解**（B\*-树按放置顺序重建），避免每层 $L$ 从头构造，大幅减少搜索量。

### 3.4 PeF 解析松弛 + 合法化（新优化，Q2 已实现 `ideal_x`）
- 先求解无重叠凸松弛（中位数坐标下降）得到每个模块的理想中心位置；
- 再在 $(L,L)$ 内做合法化装箱：Skyline 放置时在"最低层内取离理想中心最近的 $x$"（`pack_skyline(..., ideal_x=...)`），使可行摆放贴近 HPWL 优位、且在紧轮廓下更易合法化。

### 3.5 子集 CP-SAT 不可行证书（新优化）
- 取面积最大的 $K$ 个模块（如 $K=20$），用 OR-Tools `NoOverlap2D` 精确判定它们能否放入 $L\times L$；
- 若大模块子集不可行，则**整实例不可行**（大模块是装箱的最难约束），直接给不可行证书、快速抬升下界，无需等待整体 CP-SAT。

## 四、L3 双向反馈定界校验（双证书夹逼）

| 方向 | 内容 | 作用 |
|---|---|---|
| 反向（搜索→定界） | L2 任一可行布局 = **可行证书** | 给出 $d^*\le L^2/A-1$ 的上界 |
| 正向（定界→搜索） | CP-SAT 不可行证明 = **不可行证书** | 给出 $d^*\ge L_{lb}'^2/A-1$ 的下界 |
| 正向（gap 反馈） | gap $=(L_{ub}^2-L_{lb}^2)/A$ 回馈 L2 | 判断剩余压缩空间，决定是否继续精调 |

输出 $[L_{lb}',L_{ub}']$ 夹逼区间，取 $L^*=L_{ub}'$ 并附可行布局作证书，报告 gap。

---

## 五、第二阶段：最小轮廓下的 HPWL 更新（复用 Q2）

在 $L=L^*$ 下，运行问题2的完整流水线：
1. L1 终端感知初解 → L2 B\*-树-SA（**增量 HPWL + 终端引力移动 + 自适应罚**）为主、SP-AGA 对照；
2. L3 凸松弛下界 $\mathrm{HPWL}_{lb}$ 与可行证书，输出总 HPWL 与 gap；
3. 可视化：模块矩形 + Terminal 标注 + $L^*\times L^*$ 轮廓框，标注总 HPWL 与 $d^*$；
4. 与问题2（$d=0.15$）的 HPWL 对比，量化"死区压缩对线长的代价"（预期 HPWL 上升，因轮廓更紧、模块活动空间变小）。

## 六、算法对比与分工

| 算法 | 角色 | 证书类型 | 复杂度/速度 |
|---|---|---|---|
| Skyline-ILS（Q1） | 主可行性 oracle | 可行证书 | 极快 |
| B\*-树-SA（Q2） | 精调 oracle + 最终 HPWL | 可行证书 | 快 |
| CP-SAT NoOverlap2D | 整体/子集不可行证明 | 不可行证书 | 慢/限时 |
| 凸松弛+合法化（PeF） | 加速 oracle、贴近 HPWL 优位 | — | 极快 |

**推荐流水线**：$L_{lb}$ 与 $L_{ub}$ 初始化 → 二分（每层：凸松弛合法化 + Skyline-ILS 多启动给可行证书，失败则子集 CP-SAT 给不可行证书）→ 区间收敛取 $L^*$ → Q2 流水线在 $L^*$ 下求 HPWL 与可视化。

---

## 七、创新角度

1. **双证书整数二分夹逼**：启发式可行证书（上界）+ CP-SAT 不可行证书（下界），把"最小死区比例"从试错变为**可证明的搜索**，输出 $[d_{lb},d_{ub}]$ 与 gap；
2. **增量收缩 warm start**：可行解（顺序+旋转）在相邻 $L$ 间传递复用，避免重复搜索，显著加速边界精调；
3. **子集 CP-SAT 不可行证书**：对面积最大的 $K$ 个模块精确判定，用"大模块难装箱"先验快速抬升下界；
4. **密度-边长统计先验**：由 Q1 实测密度（92--94%）与正方形轮廓难度，预先收窄二分区间 $[L_{lb},L_{ub}]$；
5. **PeF 解析松弛 + 合法化**：松弛理想位置引导合法化，兼顾可行性判定与最终 HPWL（Q2 引擎 `ideal_x` 直接支持）；
6. **两阶段串接**：Q3 = Q1 装箱可行性夹逼 + Q2 最小轮廓 HPWL 更新，完整复用前两问的模型与代码，体现四层框架的统一性。
