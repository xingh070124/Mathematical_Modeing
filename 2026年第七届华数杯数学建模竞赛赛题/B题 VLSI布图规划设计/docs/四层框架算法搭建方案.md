# VLSI 布图规划 —— 四层框架算法搭建方案

> 定位：将"多源初解生成池 → 并行多目标元启发优化 → 双向反馈定界校验 → 场景适配接口"四层框架落实到
> 四个子问题的具体算法、数据结构与数据流。所有算法均以 `docs/文献综述.md` 中的文献为方法学依据。

---

## 0. 总览与数据流

```
┌────────────────────────────────────────────────────────────────────────┐
│ L4 场景适配接口层（统一模型 + 配置）                                      │
│   形状模型{矩形+C4旋转 | polyomino+C4} × 目标{面积|HPWL|混合} × 约束{自由|固定轮廓} │
└────────────────────────────────────────────────────────────────────────┘
        │ 问题配置下发（Q1–Q4 各一套）
        ▼
┌────────────────────────────────────────────────────────────────────────┐
│ L1 多源初解生成池                                                       │
│   树式贪心(B*-tree) / Skyline多规则 / 随机混合 → K个初解 → 多样性粗筛 → K'个 │
└────────────────────────────────────────────────────────────────────────┘
        │ K' 个初始解（并行分发）
        ▼
┌────────────────────────────────────────────────────────────────────────┐
│ L2 并行多目标元启发优化层                                               │
│   Q1: Skyline+ILS(主) / B*-tree+SA(对照)                                │
│   Q2: B*-tree+SA增量HPWL(主) / SP+GA(对照)                              │
│   Q3: 整数二分 + 可行性oracle（启发式可行证书 / CP-SAT不可行证书）          │
│   Q4: polyomino格点 + 精确DFS(主) / 格点BL+ILS(对照)                     │
│   多起点独立轨迹 + 精英池 + 扰动重启；字典序目标                          │
└────────────────────────────────────────────────────────────────────────┘
        │ 候选解（上界/可行证书）                ▲ 界/密度gap/不可行证明（下界）
        ▼                                        │
┌────────────────────────────────────────────────────────────────────────┐
│ L3 双向反馈定界校验层                                                   │
│   整数性引理 → 整数域搜索；密度ρ=A/(WH) → gap报告 → 引导L2；              │
│   CP-SAT NoOverlap2D → 不可行证明 → 上调下界；可行布局 → 可行性证书(上界)   │
└────────────────────────────────────────────────────────────────────────┘
```

- **L1→L2**：多源初解保证多起点多样性（多起点元启发的收敛质量与起点多样性正相关）。
- **L2→L3**：每个收敛解提交给 L3 校验，构成可行性证书（上界）。
- **L3→L2**：下界与密度 gap 反馈，判断"是否还有优化空间 / 是否需要扰动重启"。

## 1. L1 多源初解生成池

### 1.1 三类初解来源

| 编号 | 来源 | 机制 | 表示 | 主供问题 |
|---|---|---|---|---|
| S1 | 树式贪心（HSA 式） | 按 $V_i=\lambda_1\frac{h_i w_i}{HW}+\lambda_2\frac{h_i+w_i}{H+W}$ 降序，仅在可行区域内选候选点装箱 → 合法 B\*-树 | B\*-树 | Q2/Q3 |
| S2 | Skyline/BL 多规则 | 同一轮廓线框架换排序规则（面积降序 / 长边降序 / 最小间隙 / 随机）→ 多份不同解 | 坐标序列 | Q1 |
| S3 | 随机/混合 | 随机排列 + 随机预选 90° 旋转 | 坐标序列/B\*-树 | 全部（多样性保底） |

### 1.2 池管理

- 每问题生成 $K=10\sim20$ 个初解（S1/S2 各 4–8 个，S3 2–4 个）；
- **多样性粗筛**：按轮廓尺寸 $(W,H)$ 或 B\*-树拓扑哈希去重，保留 $K'=5\sim8$ 个；
- 目标：让 L2 的各条轨迹**从互不相同的解空间区域出发**。

## 2. L2 并行多目标元启发优化层

### 2.1 问题 × 算法分工（最终确认）

| 问题 | 主算法 | 对照/辅助算法 | 目标函数 |
|---|---|---|---|
| Q1 | Skyline + ILS（多启动） | B\*-树+SA | 字典序：$\min W\cdot H$，再 $\min\|W-H\|$ |
| Q2 | B\*-树 + SA（增量 HPWL） | SP + 自适应 GA | $\min \sum_k\mathrm{HPWL}_k+\gamma\sum_i\mathrm{overflow}_i$ |
| Q3 | 整数二分 + 可行性 oracle | —（见 L3 双证书） | 最小 $L$ 使 packing 可行 |
| Q4 | polyomino 格点 + 精确 DFS/CP-SAT | 格点 BL + ILS | $\min W\cdot H$（L/T 咬合） |

### 2.2 各主算法具体搭建

#### Q1 —— Skyline + ILS

```
构造：模块按排序规则降序 → 逐个放入 skyline 轮廓"最低、最左"可行位（O(n log n)）
改进（ILS）：perturbation = 随机抽取若干模块重插入 + swap/rotate；SA 式接受准则
多启动：S2 的多种排序规则 → 多条轨迹，取最优
目标：阶段1 min W·H（纯面积）；阶段2 在 WH ≤ S*+1% 内 min |W−H|
```

#### Q2 —— B\*-树 + SA（主算法）

```
表示：B*-树（根=左下角模块；左孩子贴右 x_j=x_i+w_i, y_j=y_i；右孩子在上同x取轮廓高）
解码：DFS 后序遍历 O(n log n)，输出无重叠 packing
邻域操作（每次 O(树高)）：
  Op1 旋转模块（90°，交换宽高）
  Op2 交换两模块
  Op3 移动模块到另一位置
  Op4 子树交换（HSA 全局探索，可选）
目标：cost = Σ HPWL + γ·overflow，γ 随退火动态调节（Chen-Chang 自适应权重）
加速：增量评估——只重算被移动模块所涉及线网（平均度 2.1–2.3 → 单步 O(deg)≈O(1)）
退火：几何降温 T_{k+1}=αT_k（α≈0.9–0.99），Metropolis 接受准则
终止：温度下限 / 最大迭代（n=300 时目标 ≥10^6 次评估）
```

#### Q2 —— SP + GA（对照）

```
表示：(Γ+, Γ-) 双排列，LCS 解码 O(n log n)（FAST-SP），表示完备
交叉：PMX/OX；变异：swap / inverse；精英保留
自适应：交叉率/变异率随种群适应度方差动态调整
```

#### Q3 —— 可行性 oracle（调用 L2 的 B\*-树 packing）

```
判定 L 是否可行：
  ① 启发式 packing（B\*-树+SA / Skyline）找到无重叠布局 → 返回"可行 + 布局证书"
  ② 启发式失败不判"不可行"——需 CP-SAT（L3）做不可行证明
输出：对每个 L，给出 (可行证明 | 不可行证明) 之一
```

#### Q4 —— polyomino 格点模型

```
表示：模块 i → 单位格点集 S_i ⊂ Z²；C4 旋转群作用于格点
决策变量：锚点 (x_i,y_i)∈Z² + 旋转 r_i∈C4；占用集 O_i = R_{r_i}(S_i)+(x_i,y_i)
约束：O_i ∩ O_j = ∅ (∀i≠j)
主算法：精确 DFS（首空位规范序 + 旋转等价类剪枝）或 CP-SAT
对照：格点版 BL 构造 + ILS（支持 L/T 互补咬合）
```

### 2.3 并行与多目标落地

- **并行**：$K'$ 个初解各自独立跑一条 SA/GA 轨迹（多进程/多核）；收敛后放入**精英池**，取最优；若整体密度 gap 大，用精英解做扰动重启。
- **多目标**：一律用**字典序**（Q1 面积→长宽比）或**单目标 + 罚函数**（Q2），不做真 Pareto 进化；需要 Pareto 展示时再补权重扫描。

## 3. L3 双向反馈定界校验层（创新核心）

### 3.1 理论基础

1. **整数性引理**（对任意可行 packing 依次向左/向下压缩不破坏可行性）→ 存在整数坐标最优解，$W^*,H^*,L^*\in\mathbb{Z}$ → Q1/Q3 在整数域枚举/二分；
2. **面积下界**：$WH\ge A$，密度 $\rho=A/(WH)\le 1$ 作为全局质量度量；
3. **Q3 下界**：$L_{lb}=\max(\lceil\sqrt A\rceil,\ \max_i\max(w_i,h_i))$。

### 3.2 双向反馈机制

| 方向 | 内容 | 作用 |
|---|---|---|
| 正向（定界→搜索） | 密度 gap $1-\rho$ 反馈给 L2 | 判断还有多少优化空间，是否扰动重启 |
| 正向 | CP-SAT 不可行证明 → 上调 $L_{lb}$ | Q3 二分搜索的"不可行证书"，推动 $d^*$ 下界上升 |
| 反向（搜索→定界） | L2 可行布局提交 L3 校验 | 可行性证书（上界），证明 $d^*\le d_{candidate}$ |

### 3.3 Q3 双证书夹逼（论文创新卖点）

```
输入：整数 L ∈ [L_lb, L_0.15]，L_0.15 = √(1.15A)
二分：
  每次判定 L：
    启发式 packing 成功 → 可行证书，L_ub ← L（可给出具体布局）
    启发式失败 → 调 CP-SAT 限时证明不可行：
      证明不可行 → 不可行证书，L_lb ← L
      超时未决   → 维持当前区间，二分仍继续
终止：区间 [L_lb, L_ub] 收敛（gap < 1 或达最大轮数）
输出：d* = (L_ub²)/A − 1，附可行布局证书 + gap 报告
```

### 3.4 校验工具

| 工具 | 用途 | 复杂度 |
|---|---|---|
| 密度计算 $\rho=A/(WH)$ | 全问题 gap 报告 | $O(n)$ |
| 重叠检测 | L2 解合法性校验 | $O(n\log n)$ |
| CP-SAT NoOverlap2D（OR-Tools） | Q3 不可行证明、Q1/Q4 小规模精确下界 | 限时调用 |
| 整数性验证 | Q1/Q3 整数坐标方案合法性 | $O(n)$ |

## 4. L4 场景适配接口层（统一模型 + 配置）

不做面向对象框架，做成**统一数学模型 + 四套配置**：

```python
# 统一求解器输入（伪代码）
config = {
  "Q1": dict(shape="rect",   rotation="C4",   outline="free",
             objective="area+aspect",            nets=False),
  "Q2": dict(shape="rect",   rotation="C4",   outline="fixed(L)",
             objective="HPWL+overflow",          nets=True),
  "Q3": dict(shape="rect",   rotation="C4",   outline="search(L*)",
             objective="min_L",                  nets=False),
  "Q4": dict(shape="polyomino", rotation="C4", outline="free",
             objective="area",                   nets=False),
}
# 同一套：L1 生成 → L2 优化 → L3 校验 流水线，按 config 选择具体实现
```

| 配置项 | Q1 | Q2 | Q3 | Q4 |
|---|---|---|---|---|
| 形状模型 | 矩形 | 矩形 | 矩形 | polyomino(L/T) |
| 旋转群 | $C_4$ | $C_4$ | $C_4$ | $C_4$ |
| 轮廓 | 自由 | 固定 $L=\sqrt{1.15A}$ | 二分搜索 | 自由 |
| 线网/端子 | 无 | 有（固定端子） | 无 | 无 |
| 目标 | 面积→长宽比 | HPWL | 最小 $L$ | 面积 |
| 主算法 | Skyline+ILS | B\*-树+SA | 二分+双证书 | 精确DFS/CP-SAT |

## 5. 验证与论文叙事

1. **收敛证据**：多起点 vs 单起点收敛曲线对比表（L1/L2 有效性的实证）；
2. **gap 报告**：Q1/Q3 输出密度 $\rho$ 与 $[d_{lb},d_{ub}]$ 夹逼区间（L3 有效性的实证）；
3. **对照实验**：Q2 用 SP+GA 与 B\*-树+SA 对比 HPWL（L2 分工合理性的实证）；
4. **Q3 双证书**：附"可行证书布局图 + 不可行证明记录"，证明 $d^*$ 的上下界（核心创新）。

## 6. 实现顺序建议

1. 基础数据结构：矩形模块、线网解析（.blocks/.nets）、增量 HPWL 评估；
2. L2-Q1：Skyline+ILS（最快见效）；
3. L2-Q2：B\*-树+SA（主算法，含增量评估）；
4. L3-Q3：整数二分 + CP-SAT 不可行证书；
5. L4-Q4：polyomino 格点模型 + 精确 DFS；
6. L1：初解池与多起点调度；
7. L3：密度 gap 反馈回路与精英池；
8. 论文图表与结果表。
