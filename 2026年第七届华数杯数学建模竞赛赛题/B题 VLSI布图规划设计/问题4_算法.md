# 问题4 算法设计：L/T 型异形模块 Packing（矩形切割 + 刚性链接）的求解算法

配套建模见《问题4_数学建模.md》。总体策略：**在问题1四层框架与算法基础上适当修改**，L4 场景适配层把配置切到 Q4（`shape=polyomino, rotation=C4, outline=free, objective=area`），第 1–3 层复用主线，仅把"放置单个矩形"改为"放置带刚性链接的复合矩形对象"：

> **L1 多源初解生成（复合形状 Skyline/BL）→ L2 并行元启发（复合形状 Skyline-ILS 主 · B\*-树-包围盒近似对照）→ L3 双向反馈定界（面积下界 + 因子枚举 + CP-SAT/精确 DFS 验证）→ L4 场景适配**

---

## 一、相对问题1算法的修改点（核心）

| 问题1算法组件 | 问题4修改 |
|---|---|
| 模块表示单个矩形 $(w_i,h_i)$ | 复合矩形对象：子块 $\{R_{m,k}=(w_{m,k},h_{m,k})\}_{k=1}^{K_m}$ + 局部偏移 $(a_{m,k},b_{m,k})$ |
| 旋转 $r_i\in\{0,1\}$ | C4 旋转群 $r_m\in\{0,1,2,3\}$，子块尺寸与偏移随旋转查表变换 |
| 放置"$w\times h$ 窗口空闲判定" | 放置时校验模块**全部子块的占用格**空闲且不越界（刚性链接由"整模落位"天然保证） |
| 非重叠约束 | 跨模块子块间沿用矩形析取判定（C1'），同模块子块由切割保证不相交 |
| 包围盒 $W=\max(x_i+\hat w_i)$ | $W=\max_{m,k}(x_{m,k}+w_{m,k})$，$H$ 同理 |

**关键：刚性链接不引入额外搜索负担**——每个模块仍只有 1 个锚点 + 1 个旋转，子块位置由固定偏移确定，放置时整体落位即可，等价于"放置一个异形刚体"。

---

## 二、L1 多源初解生成池（复合形状 Skyline/BL 构造）

- **数据结构**：布尔占用位图 $\mathrm{OCC}[0..W)\times[0..H)$；
- **放置**：对模块 $m$ 的每个旋转 $r\in C4$，在可行锚点区域扫描，找到使**全部子块占用格空闲且不越界**的候选锚点，按"最低、最左（或最小残留空隙）"准则落位并更新位图；
- **排序规则复用问题1**：面积降序 / 长边降序 / 周长降序 / LFF / 随机；旋转贪心选取 $C4$ 中放置位置更优者；
- **多样性粗筛**：按轮廓尺寸 + 结构差异保留 $K'$ 个初解。

---

## 三、L2 主算法：复合形状 Skyline-ILS（复用 Q1）

在问题1的 Skyline+ILS 基础上直接改造：
- 解表示 $(\text{放置顺序},\text{各模块旋转}\in C4)$；
- 扰动：随机抽 $k$ 个模块重插 / 交换两模块 / 翻转旋转（$C4$ 中随机改一档），Metropolis 接受准则 $\min(1,e^{-\Delta/T})$；
- 多起点 + 精英池 + 强扰动重启，取字典序最优（面积 → 长宽比）；
- 每次评估重新复合装箱并计算包围盒 $(W,H)$，$O(nWH)$ 向量化（numpy 位图），小规模极快。

---

## 四、L2 对照算法：B\*-树-SA（包围盒近似，明确局限）

- B\*-树节点对应单个矩形，无法直接表达刚性复合模块；
- **近似方案**：把每个异形模块按其**包围盒矩形**作为一个 B\*-树节点参与装箱；
- **局限（须在论文中说明）**：包围盒会占用异形模块的缺口区域，无法实现凹凸咬合，故**达不到 100% 密度**、最优面积劣于精确解——仅作为与主算法/精确解的对照，验证"咬合收益"（本实例包围盒近似面积 $>24$，而复合形状精确解 $=24$）。

---

## 五、L3 定界与验证：CP-SAT / 精确 DFS（4 模块实例）

对验证实例，用**修正模型 + 精确搜索**给出可证明的最优面积：

```
输入：子块 R_{m,k} 与偏移 (a_{m,k},b_{m,k})，A=24
下界：S* >= A；在 A 的整数因子对 (W,H) 上检验可铺砌性
对每个 (W,H)（优先面积最小者）：
    精确搜索（首空位规范序 DFS / CP-SAT）：
        放置 = 选模块 m、旋转 r∈C4、锚点置于首空闲格，
               校验该模块全部子块占用格空闲且不越界（硬链接整体落位）
        剪枝：剩余模块面积 > 当前空格数 → 回溯；旋转/镜像等价剪枝
        成功 → (W,H) 可行（输出布局），否则不可行
输出：最小可行面积 S* 与最优摆放
```

- **首空位规范序**：始终把下一模块锚点放在"最左下首空闲格"，消除排列冗余；
- **硬链接整体落位**：放置即校验全部分子块，天然满足链接约束（G1）；
- **旋转/对称剪枝**：C4 旋转等价与镜像等价只保留一个代表分支；
- **CP-SAT 可选**：把子块坐标写为 $x_{m,k}=x_m+a_{m,k}(r_m)$（线性链接）+ 跨模块析取非重叠，用 OR-Tools 精确求解，与 DFS 互为验证。

## 八、创新角度

1. **矩形切割 + 刚性链接**：把异形模块建模为"若干矩形子块 + 固定相对位移"的刚体，模型与问题1逐条对应、**仅新增一条线性链接约束**，最大化复用前三个问题的建模与 Skyline/CP 框架；
2. **链接约束烘进变量**：子块坐标 = 锚点 + 固定偏移，硬约束被参数化自然满足，无需罚函数近似，精确性与可证明性都得以保留；
3. **复合形状 Skyline-ILS**：放置时整模落位、只换"形状基元"，问题1的装箱/局部搜索引擎零重构复用；
4. **B\*-树包围盒对照**：诚实呈现 B\*-树无法表达刚性复合模块的局限（包围盒浪费缺口），并以精确解 $=24$ 与包围盒近似的面积差量化"咬合收益"；
5. **面积下界 + 因子枚举 + 首空位精确 DFS**：小实例在 $A$ 的因子对上检验可铺砌性，面积最优性简化为"是否存在完美铺砌"，可证明 $S^*$。
