# 问题3 数学建模：最小死区比例（最小可行正方形轮廓）

## 一、问题重述

在问题2的基础上（固定正方形轮廓、模块之间存在连接关系），求使得存在一个可行布局方案的最小死区比例 $d^*$。由于死区比例与轮廓边长满足 $L=\sqrt{A(1+d)}$，最小化 $d$ 等价于最小化可行正方形边长 $L$：随着 $L$ 减小，空白区被压缩，模块越难以在互不重叠且不超出轮廓的前提下全部放入。求得 $d^*$ 后，再基于问题2所建立的模型在 $L=\sqrt{A(1+d^*)}$ 的轮廓下更新三组芯片的总 HPWL 与模块摆放可视化。

与问题1/2的本质区别：问题1优化面积、问题2在给定轮廓内优化线长，而问题3求解的是**可行性边界**——在"存在可行布局"的临界状态附近搜索最小轮廓，是"可行性问题（feasibility）"而非"最优化问题"。

## 二、模型假设

1. 模块为刚体矩形，仅可平移与 90° 旋转（旋转即交换宽高）；
2. 模块间不允许重叠，边界允许贴合（共边/共点）；
3. 芯片轮廓为正方形 $[0,L]\times[0,L]$，边长 $L$ 为**待求的决策量**（区别于问题2的固定值），由公式 $L=\sqrt{A(1+d)}$ 与死区比例 $d$ 一一对应；
4. 可行性判定仅考虑 HardBlock：Terminal 不占面积、不参与重叠与边界约束，故在判定 $L$ 是否可行时无需考虑 Terminal；仅在最末步"更新 HPWL"时才引入 Terminal 与线网；
5. 每个模块的引脚位于几何中心，线长以 HPWL 估算（用于最末步 HPWL 更新）。

## 三、符号说明

| 符号 | 含义 |
|---|---|
| $\mathcal{B}=\{1,\dots,n\}$ | HardBlock 集合（n100: $n=100$；n200: $200$；n300: $300$） |
| $w_i,h_i$ | 模块 $i$ 原始宽、高 |
| $r_i\in\{0,1\}$ | 模块 $i$ 是否旋转 90° |
| $\hat w_i,\hat h_i$ | 旋转后实际宽、高 |
| $(x_i,y_i)$ | 模块 $i$ 左下角坐标 |
| $A=\sum_i w_ih_i$ | 模块总面积（常数） |
| $d$ | 死区比例，$d=L^2/A-1$ |
| $L$ | 正方形芯片边长（决策量） |
| $L^*$ | 最小可行边长 |
| $d^*$ | 最小死区比例，$d^*=(L^*)^2/A-1$ |
| $L_{lb}$ | 边长下界 |
| $\text{Feasible}(L)$ | 可行性判定 oracle（返回 可行/不可行/未知） |
| $\mathrm{HPWL}_k$ | 线网 $k$ 的半周长线长（最末步更新用） |

## 四、决策变量与约束

**旋转尺寸变换**
$$\hat w_i=(1-r_i)w_i+r_ih_i,\qquad \hat h_i=r_iw_i+(1-r_i)h_i$$

**非重叠约束**（对任意 $i<j$，四析取其一）
$$(x_i+\hat w_i\le x_j)\lor(x_j+\hat w_j\le x_i)\lor(y_i+\hat h_i\le y_j)\lor(y_j+\hat h_j\le y_i)\tag{C1}$$

**边界约束**（$L$ 为变量，区别于问题2）
$$0\le x_i,\quad x_i+\hat w_i\le L,\quad 0\le y_i,\quad y_i+\hat h_i\le L,\quad \forall i\in\mathcal{B}\tag{C2}$$

**可行性定义**：称 $L$ 可行，当且仅当存在 $(x,y,r)$ 同时满足 (C1) 与 (C2)。

## 五、目标函数

**主目标（最小可行边长 / 最小死区比例）**
$$L^*=\min\Big\{L\in\mathbb{Z}_{>0}:\ \text{Feasible}(L)\Big\},\qquad d^*=\frac{(L^*)^2}{A}-1\tag{P3}$$

**次目标（字典序第二级，题目要求的 HPWL 更新）**：在 $L=L^*$ 下，沿用问题2模型最小化总 HPWL
$$\min_{x,y,r}\ \sum_{k\in\mathcal{N}}\mathrm{HPWL}_k\quad \text{s.t.}\ (C1),(C2),\ L=L^*\tag{O3}$$
即"先求最小死区比例，再在最小轮廓内优化线长"，与题目"基于问题2模型和死区比例最小值更新总 HPWL"的要求一致。

## 六、理论性质

**性质1（决策版本 NP-complete）**：判定"能否将 $n$ 个矩形无重叠放入 $L\times L$ 正方形"是经典 Square Packing 决策问题，为 NP-complete；$n=100\sim300$ 下精确判定无法在时限内闭合，需启发式给可行证书、约束规划给不可行证书。

**性质2（可行性关于 $L$ 单调，支撑整数二分）**：若 $L$ 可行，则 $L+1$ 必然可行——因为 $L$ 下的任意可行摆放整体不变地落在 $(L+1)\times(L+1)$ 内仍满足 (C1)(C2)。故可行性在整数 $L$ 上单调，可在 $[L_{lb},L_{ub}]$ 上**二分搜索**最小可行边长。

**性质3（整数性引理）**：由问题1的压缩论证，存在整数坐标的最优可行解，故 $L^*\in\mathbb{Z}_{>0}$，二分域可限制在整数上。

**性质4（边长与死区下界）**：
$$L^*\ge L_{lb}=\max\Big(\lceil\sqrt{A}\rceil,\ \max_i\max(w_i,h_i)\Big),\qquad d^*\ge d_{lb}=\frac{L_{lb}^2}{A}-1$$
**实测下界**：n100: $L_{lb}=424,\ d_{lb}=0.153\%$；n200: $L_{lb}=420,\ d_{lb}=0.401\%$；n300: $L_{lb}=523,\ d_{lb}=0.131\%$。（该下界假定面积利用率 100%，一般不可达，仅作夹逼下界。）

**性质5（上界证书与密度视角）**：任一在 $L\times L$ 内无重叠的可行摆放即为**可行证书**，给出 $L^*\le L$ 与 $d^*\le L^2/A-1$；同时以 packing 密度 $\rho=A/L^2$ 度量轮廓压缩程度。问题1自由轮廓实测密度达 92--94\%，而正方形轮廓（长宽比固定 1:1）更受约束，可行性边界处密度通常低于自由轮廓，这为 $L^*$ 的取值提供了先验范围。

## 八、模型评价与扩展

- **优点**：单调性（性质2）使"最小死区比例"从单纯试错变为可证明的整数二分搜索；双证书（启发式可行上界 / CP-SAT 不可行下界）给出可验证的夹逼区间；与问题1/2无缝衔接——可行性判定复用问题1的装箱工具、HPWL 更新复用问题2的布图工具。
- **局限**：启发式只能提供可行上界，不可行证明依赖 CP-SAT 且大规模实例难以闭合，最终 $d^*$ 是夹逼区间的代表值而非严格最优；$d_{lb}$ 假设 100% 面积利用率，一般不可达，作为下界较松。
- **扩展**：可利用问题1实测密度（92--94%）构造更紧的先验区间缩小二分范围；对"大模块子集"做精确判定（大模块是装箱最难约束）快速抬升下界；解析松弛放置 + 合法化（PeF 范式）加速可行性判定。
