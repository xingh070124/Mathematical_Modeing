- **对比四**：本题所需的一维解耦（低维简化）模型与文献中的多物理场耦合模型 —— 哪一套更适合本问题。

## 0. 结论摘要

### 对比一

**feishu.md 的两套路线按原文逐字实现后，都不成立**，且失效原因互不相同：

| 缺陷 | 位置 | 证据 |
|---|---|---|
| 本征值表全错 | §6.1 表：`~2.0, ~5.0, ~8.0, ~11.0` | 真值 `1.4184725188, 4.1664696010, 7.2084784644, 10.3082731535` (F10_1–F10_4) |
| 展开系数公式错 | §6.1 `A_k = 2(T₀−T∞)/(λ_k R J₁(λ_k R))` | 与正确系数差因子 `1+(λ_k R/Bi)²` (F14)；该级数在 `r=R` 处重构常数 1 得 **11.52** (F16) |
| 内部差分符号错 | §5.3 `d_i = a_i T_{i−1} + (2−b_i)T_i + c_i T_{i+1}` | M=200 时 **t=127 s 发散** (F30_M200) |
| 表面时间尺度与内部不一致 | §5.3 内部为 CN、表面为后向 Euler 尺度 | 误差 **70.78 K** 不收敛 (F20_M100_leaddoc) |

**修正后两条路线都很好，而且互相印证到 3.49e-6 K (F40)。** 但适用范围不同：

| | 半解析（Bessel+Duhamel） | 数值（CN/BDF2） |
|---|---|---|
| 可处理非线性水分方程 | **否**（线性化误差 4.19e-2 kg/kg，F50） | **是** |
| 温度场精度 | 机器精度（级数解） | 二阶格式，M=400 时 6.66e-6 K (F22_M400_exact) |
| 成本（0–1800 s） | 与 r 网格无关（见 §1.8） | ∝ 时间步数 × M |
| 依赖 | 本征值/系数公式必须正确 | 表面几何因子必须正确 |

**判定**：**数值路线是本题的主力方法**（唯一能算水分）；**半解析路线不可替代地用作温度的独立验证**，
并且它是 `feishu.md` §6.3 那三条验收判据唯一能被真正满足的地方。

### 对比四

**本题不需要、也不应使用文献那种多物理场耦合模型。** 理由分三层，全部可量化：

1. **题面已经规定了耦合层级**：附录2 给常数 ρ、c_p、k 且 D 只依赖 C ⇒ 问题1 是**规定解耦**的；
   附录3/4 才让 ρ、c_p、k 随 C 变、D 随 C 与 T 变 ⇒ 问题2–4 才**规定耦合**。
   在问题1 上改用附录3 的物性律，1800 s 内温度最大偏差 **1.4019 K**、水分最大偏差 **0.1383 kg/kg** (F60/F61)。
2. **耦合确实有价值，但只在问题2–4 显现**：即使同在附录3 内部，把 Arrhenius 温度因子冻结，
   水分偏差也有 **7.55e-2 kg/kg** (F70)；干燥全程 α 变化 **48.2%** (F71)。
3. **文献模型在本问题上不可用作基线**：胡众欢等 (2020) 的三维多物理场模型
   **通篇没有初始条件与边界条件**，且缺少渗透率 k、水活度 a_w、饱和蒸汽浓度 c_v,sat 的取值，
   因而**无法被重实现**；其验证只有两个数字（最大相对误差 13.3%、绝对误差 0.016）。
   作者自己把强耦合降为弱耦合，且该降阶**未做任何量化**。

## 1. 对比一：半解析路线 vs 数值路线

### 1.1 两套路线在 feishu.md 中的原文位置

- **数值路线**：§5「数值方案」。§5.1 网格（M=200, Δt=0.25 s）、§5.2 `r=0` 奇点（L'Hôpital）、
  §5.3 温度方程 Crank–Nicolson、§5.4 水分方程 BDF2 + Newton、§5.5 PCHIP 环境插值。
- **半解析路线**：§6「半解析验证（加分大项）」。§6.1 Bessel 本征展开、§6.2 Duhamel 原理（时变环境）、
  §6.3 验证判据。

§6.3 给出的验收判据是：最大绝对误差 < 10⁻⁵ K、收敛阶 ≈ 2.00、相邻网格误差比 ≈ 4。
本报告用这三条判据直接检验两套路线 —— 而且用的是比 §6 更强的参照：一条**独立构造**的
半解析解，而不是自己验证自己。

### 1.2 参照解（不使用 feishu.md 的 §6.1 公式）

半解析参照解按下面方式独立构造，推导记录在 `src/feishu_compare.py` 文件头：

齐次 Robin 模态为 `J₀(λ_n r)`，`x_n = λ_n R` 满足

```
x_n J₁(x_n) = Bi J₀(x_n),      Bi = hR/k = 1.388889
```

正确展开系数（**不是** feishu.md §6.1 的 `A_k`）：

```
c_n = 2 J₁(x_n) / ( x_n ( J₀(x_n)² + J₁(x_n)² ) )
```

该系数已用**两条独立途径**验证闭式与数值积分一致到 10 位有效数字
（详见 `outputs/wolfram_feishu_audit.log` §W2）：
闭式 `1.265822137` vs 数值投影 `1.265822137`（第1项），第2–6项同样 10 位一致。

对时变环境用 Duhamel 的模态形式，`b_n' + μ_n b_n = −c_n T∞'(t)`，`μ_n = αλ_n²`，
分段线性 `T∞` 上可精确积分。该参照解与数值解独立算得一致到 3.49e-6 K (F40)，
即参照解本身已被交叉验证。

**独立性核查（防止"自证")**：`series_T` 与 `solve_T` 共用 `eigen()` 求根本征值，
因此两者的一致性可能是循环的。为此另跑了一项对照
（`src/audit_series_cross.py`）：把本报告的半解析解与 **session 1 中独立编写的**
`src/q1_solve.py::robin_cylinder_eigen / robin_cylinder_theta`（不同的求根区间扫描、
不同的系数代码路径、不同的数组布局）逐点比较：

| 比较对象 | 结果 |
|---|---|
| 本征值 `x_k`（k=1..8） | 两者之差 ≤ 3.6e-15 |
| 展开系数 `c_k`（k=1..8） | 打印位数内完全相同 |
| 级数求值 T(r,t)（常 T∞=50 °C，t=60/300/900/1800 s，r/R=0…1） | 最大差 **5.684e-14 K** |
| 常数 1 的重构 `Σ c_k J₀(x_k)|_{r=R}` | 两者差 ≤ 1.9e-15（n_modes=8…100） |

两个**独立实现**在机器精度上一致 ⇒ 本报告的半解析参照解不是自证，
且 F40 那个 3.49e-6 K 的数值-半解析一致性是**两条独立路线**之间的一致性。

### 1.3 §6.1 本征值表的逐字检验

`feishu.md` §6.1 给出一张「前4个本征值（Bi=1.389时）」表，值为 `~2.0, ~5.0, ~8.0, ~11.0`，
并在下文注明「具体值需用数值方法求解超越方程」。

| k | feishu.md §6.1 | 实际 λ_k R | 残差 `x J₁ − Bi J₀` |
|---|---|---|---|
| 1 | ~2.0 | **1.4184725188** (F10_1) | −4.4408920985e-16 (F17_1) |
| 2 | ~5.0 | **4.1664696010** (F10_2) | 2.2204460493e-16 (F17_2) |
| 3 | ~8.0 | **7.2084784644** (F10_3) | 7.7715611724e-16 (F17_3) |
| 4 | ~11.0 | **10.3082731535** (F10_4) | 9.9920072216e-16 (F17_4) |

四个值全部不符，且**偏大 6.7–41%**（表值 2.0 / 5.0 / 8.0 / 11.0 相对真值
1.4185 / 4.1665 / 7.2085 / 10.3083 分别高出 41% / 20% / 11% / 6.7%）。
前 8 个根的最大残差为 4.94e-15 (F17)，即求根残差处于双精度舍入量级，

⇒ 这张表是**占位值，不是任何正确计算的结果**；文中自己也注明
「具体值需用数值方法求解超越方程」，即作者确实没有算过。

> 影响：§6.1 的 λ 用于 `T(r,t) = T∞ + Σ A_k e^{−λ_k²αt} J₀(λ_k r)`。λ 错会同时改变
> 衰减速率与空间形状，因而**该解析解的每一处都是错的**。

### 1.4 §6.1 展开系数公式的逐字检验

`feishu.md` §6.1 写：

```
A_k = 2/(R² J₀²(λ_k R)) ∫₀^R r [T₀ − T∞] J₀(λ_k r) dr  =  2(T₀ − T∞)/(λ_k R J₁(λ_k R))
```

等号右端那个「化简结果」是错的。正确投影系数是 `c_k`（见 §1.2），两者之比为

```
c_k / A_k(feishu) = 1 / (1 + (λ_k R / Bi)²)
```

**该比值已由符号推导证实**（`outputs/wolfram_feishu_audit.log` §W4），不是数值拟合出来的：
把特征条件 `J₁ = Bi·J₀/x` 代入 `c_k/A_k = J₁²/(J₀²+J₁²)`，Wolfram 返回

```
625 / (625 + 324 x²)
```

而 `Bi = 25/18 ⇒ Bi² = 625/324`，故 `1/(1+(x/Bi)²) = 625/(625+324x²)`，**与 Wolfram 结果恒等**。

数值检验（`outputs/feishu_compare.log` A1）逐项吻合到 6 位：

| k | λ_k R | c_k（正确） | A_k（feishu） | c_k/A_k | 1/(1+(x/Bi)²) |
|---|---|---|---|---|---|
| 1 | 1.418473 | 1.2658221367 (F12) | 2.5861431395 (F13) | 0.489463 (F14) | 0.489463 |
| 2 | 4.166470 | −0.3779735278 | −3.7794135076 | 0.100009 | 0.100009 |
| 3 | 7.208478 | 0.1749635067 | 4.8879877959 | 0.035795 | 0.035795 |
| 4 | 10.308273 | −0.1037590628 | −5.8193727782 | 0.017830 | 0.017830 |
| 5 | 13.427161 | 0.0701872141 | 6.6299995535 | 0.010586 | 0.010586 |
| 6 | 16.554544 | −0.0514113586 | −7.3553735523 | 0.006990 | 0.006990 |

因为 `(λ_k R/Bi)²` 随 k 单调增（λ_k 近似等间距增长），**feishu 的 A_k 相对正确系数发散**：
比值从 0.489 一路降到 0.00699。也就是说，`feishu.md` 的级数在**高阶项上越来越错**，
而高阶项恰恰控制表面附近的收敛。

**决定性检验**：用前 8 项重构常数 1（因为 `Σ c_k J₀(λ_k ρ) ≡ 1`）：

|---|---|---|

| 0.50 | 0.99772822 | 0.43520130 |

正确系数重构出的误差只来自 8 项截断（0.036186，F15）；feishu 的系数在 `r=R` 处给出
**11.52**，误差 10.52 (F16) —— 即 **R 处的误差是待重构常数本身量级的 10 倍**，
而 `r=R` 正是 Robin 边界条件所在的位置。

### 1.5 §5.3 差分格式的逐字检验

`feishu.md` §5.3 声明「在 (t_n, t_{n+1}) 时间中点做 C-N 离散」，并给出内部节点系数

```
a_i = −(αΔt/(2Δr²))·(i−0.5)/i
b_i = 1 + αΔt/Δr²
c_i = −(αΔt/(2Δr²))·(i+0.5)/i
d_i = a_i T_{i−1}^n + (2−b_i) T_i^n + c_i T_{i+1}^n
```

以及表面节点（i=M）

```
a_M = −2αΔt/Δr²
b_M = 1 + 2αΔt/Δr² + 2αhΔt/(kΔr)
d_M = (2−b_M) T_M^n − a_M T_{M−1}^n + 2αhΔt/(kΔr)·T∞^{n+1}
```

**内部系数是对的**。`b_i = 1 + αΔt/Δr²` 正是 CN（θ=1/2）值（后向 Euler 应为 `1 + 2αΔt/Δr²`），
且 `−a_i`、`−c_i` 与 `(2−b_i)` 恰好构成正确的 CN 右端。

**`r=0` 节点也是 CN 尺度，且是对的**：文中 `b_0 = 1 + 2αΔt/Δr²`、`c_0 = −2αΔt/Δr²`。
以对称性 `T_{−1}=T_1`，`r=0` 的空间算子为 `L₀ = 4(T_1−T_0)/Δr²`（由 L'Hôpital 得），
故 CN 尺度下 `(αΔt/2)·4/Δr² = 2αΔt/Δr²` 与 `c_0` 完全一致（F6）。

**即内部与 `r=0` 都在 CN 尺度上，只有表面行例外** —— 这使「表面行混用了时间离散尺度」
成为唯一自洽的诊断，而不是网格或其它环节的问题。

**但 `d_i` 的符号是错的。** 因为 `a_i`、`c_i` 本身是负数，文中写的 `+a_i T_{i−1}` 与 `+c_i T_{i+1}`
等于减去扩散项，与左端同号。逐字实现（`doc_signs`）的后果：

| M | 发散时刻 |
|---|---|
| 200 | **t = 127.00 s** (F30_M200) |
| 800 | **t = 62.50 s** (F30_M800) |

网格加密反而**更早**发散 —— 这是格式病态（反耗散）而非截断误差的特征。

**表面行的第二个缺陷：时间离散尺度与内部不一致。** 内部用 CN（θ=1/2），
表面行却是后向 Euler 的尺度（θ=1）：`a_M = −2αΔt/Δr²` 是 CN 值 `−αΔt/Δr²` 的 **2 倍**，
`b_M` 的增量同样是 CN 值的 2 倍。而且 `d_M` 用了 `(2−b_M)` 形式，使表面行的
左端为 θ=1、右端为 θ=0 —— 一个**混阶**的行。

空间加密（Δt=0.5 s，t=300 s，常 T∞=50 °C）：

| M | 逐字（`lead_doc`） | 误差比 | CN尺度+leading几何 | 误差比 | CN尺度+精确半CV | 误差比 |
|---|---|---|---|---|---|---|
| 50 | 70.8475 K (F20_M50) | — | 2.99399e-2 (F21_M50) | — | 5.41512e-4 (F22_M50) | — |
| 100 | 70.7814 K (F20_M100) | 1.001 | 1.51143e-2 (F21_M100) | 1.981 | 1.34076e-4 (F22_M100) | 4.039 |
| 200 | 70.7483 K (F20_M200) | 1.000 | 7.59311e-3 (F21_M200) | 1.991 | 3.21471e-5 (F22_M200) | 4.171 |
| 400 | 70.7317 K (F20_M400) | 1.000 | 3.80520e-3 (F21_M400) | 1.995 | 6.65961e-6 (F22_M400) | 4.827 |

时间加密（固定 M=100）：

| Δt | 逐字（`lead_doc`） | CN+leading | CN+精确半CV |
|---|---|---|---|
| 1 | 70.781414 | 1.511125e-2 | 1.285678e-4 |
| 0.25 | 70.781390 | 1.511505e-2 | 1.354535e-4 |
| 0.0625 | 70.781389 | 1.511529e-2 | 1.358839e-4 |

三点结论：

1. **逐字格式不收敛**：误差停在 70.78 K，且**对 Δt 完全不敏感**
   （Δt=1 时 7.0781413981e+01 K，Δt=1/64 时 7.0781388436e+01 K；两者之差见 F26）。
   误差不是时间离散误差，表面行收敛到了**另一个边界条件**的解。
2. **修好 θ 尺度后**（`lead_cn`）：误差比 ≈2 ⇒ **一阶**，M=400 时 3.81e-3 K。仍不满足 §6.3 的 1e-5 K。
3. **再把表面的 O(Δr) 几何因子修好**（`exact_cn`，`f_M = A_{M−1/2}/(Δr V_M) = 2(M−0.5)/(Δr²(M−0.25))`）：
   误差比 ≈4 ⇒ **二阶**，M=400 时 6.66e-6 K，**满足 §6.3 的 1e-5 K 与收敛阶 2.00**。

> 关于题面要求的四位小数（阈值 5e-5 K）：`exact_cn` 在 M≥约 150 即达标；
> 只有一阶的 `lead_cn` 需要 M ≈ 3×10⁴ 才达标。

### 1.6 两条路线互相印证

在真实算例（0–1800 s，附件1 时变 T∞）上，用**修正后**的两条路线各算一次温度场：

| 量 | 值 |
|---|---|
| 数值 CN（M=1600, Δt=2⁻⁵ s）vs 半解析（400 项）最大绝对差 | **3.4936501265e-6 K** (F40) |
| T(1800 s, r=0) 数值 / 半解析 | 306.72583087 K（两者在该位小数上一致，F43） |
| T(1800 s, r=R) 数值 / 半解析 | 309.93578369 K（同上，F44） |
| 环境 T∞(1800 s) | 314.6630 °C |

二者一致到 3.5e-6 K，**远优于四位小数阈值 5e-5 K**。这同时说明：
数值格式（修正后）正确，且半解析参照解正确 —— 两个独立实现互相验证。

### 1.7 半解析路线能否用于水分方程？

不能。半解析（本征展开 + Duhamel）要求方程线性；水分方程
`D(C) = 7e-9 exp(−0.89/C)` 是强非线性：`D(2.55) = 4.9377e-9`，而 C 降到 0.15 时
`D → 1.85e-11`，量级跨度巨大。

量化：用 `C = C₀` 处的常数 `D` 走半解析，与真实非线性数值解比较：

| 量 | 值 |
|---|---|
| `Bi_m = h_m R / D(C₀)` | 3.2404045432 (F53) |
| C(1800 s, r=0) 非线性 | 2.5499922528 (F51) |
| C(1800 s, r=R) 非线性 | 1.5102912463 (F52) |
| max\|C_线性化 − C_非线性\| | **4.1861810290e-2 kg/kg** (F50) |

4.19e-2 kg/kg 是四位小数阈值（5e-5）的 **800 倍以上**。因此：

- 温度：半解析可用（且是极好的验证）；
- 水分：**只能数值求解**。

## 2. 对比四：解耦的一维模型 vs 多物理场耦合模型

### 2.1 本题的耦合层级是题面规定的，不是自选的

题面（`docs/A题.md`，附录2/3/4）给出的物性是**分阶段**的：

| | 附录2（问题1） | 附录3（问题2、3） | 附录4（问题4） |
|---|---|---|---|
| ρ | 820（常数） | 650 + 128C | 760 + 90C |
| c_p | 2600（常数） | 1450 + 2736C/(C+1) | 1850 + 2150C/(C+1) |
| k | 0.36（常数） | 0.21 + 0.38C/(C+1) | 0.12 + 0.20C/(C+1) |
| D | 7e-9·exp(−0.89/C) | 2.4e-3·exp(−0.45/C)·exp(−3850/T) | 4.2e-4·exp(−0.30/C)·exp(−3850/T) |
| 耦合性质 | **单向**：D 只依赖 C，温度方程不含 C | **双向**：物性依赖 C，D 依赖 C **与 T** | **双向** |

所以：

- 问题1：**规定解耦**。温度方程与水分方程确实可以分开求解（这一点 `feishu.md` §1.2 是对的）。
- 问题2–4：**规定耦合**，且是双向的。`feishu.md` §1.2 那句「两个过程单向解耦……
  可独立求解」若被当作通篇结论，**只对问题1成立**。

### 2.2 量化：把附录3 的物性律用到问题1 上，要付多少代价

同一时间窗（0–1800 s）、同一环境激励（附件1）、同一网格（M=400, Δt=0.5 s），
只替换物性律（附录2 → 附录3）：

| 量 | 值 |
|---|---|
| max\|T_附录3 − T_附录2\| | **1.4019076018 K** (F60)，出现在 r=0.0138 m, t=1800 s |
| max\|C_附录3 − C_附录2\| | **0.13834689131 kg/kg** (F61) |
| T(1800 s, r=0)：附录2 / 附录3 | 306.72642796 / 305.34033311 K (F64/F65)，差 −1.386095 K |
| α(C₀) 比 附录3/附录2 | 0.85770461016 ⇒ **−14.23%** (F62) |
| D(C₀) 比 附录3/附录2 | 1.1425829195 ⇒ +14.26% (F63) |

初态物性对照：

| | ρ | c_p | k | D | α |
|---|---|---|---|---|---|
| 附录2 | 820.0 | 2600.0 | 0.3600 | 4.9377e-9 | 1.6886e-7 |
| 附录3 | 976.4 | 3415.3 | 0.4830 | 5.6417e-9 | 1.4483e-7 |

即：**用错物性律的代价是 1.4 K 与 0.138 kg/kg**，远超四位小数要求。
反过来说，这说明**在问题1 上「解耦」不是一个近似选择，而是题面要求** ——
用耦合模型去做问题1 才是错的。

### 2.3 量化：耦合本身值多少（附录3 内部）

同在附录3 内，把 Arrhenius 温度因子 `exp(−3850/T)` 冻结在初温 `T₀`，
其余照旧（即切断 T→D 这一条反馈）：

| 量 | 值 |
|---|---|
| max\|dC\| 因切断 T→D 反馈 | **7.5472916081e-2 kg/kg** (F70) |

而干燥全程（C 由 2.55 降到 0.15）物性变化：

| C | ρ | c_p | k | α | D |
|---|---|---|---|---|---|
| 2.55 | 976.4 | 3415.3 | 0.4830 | 1.4483e-7 | 5.6417e-9 |
| 1.00 | 778.0 | 2818.0 | 0.4000 | 1.8245e-7 | 4.2916e-9 |
| 0.50 | 714.0 | 2362.0 | 0.3367 | 1.9963e-7 | 2.7364e-9 |
| 0.15 | 669.2 | 1806.9 | 0.2596 | 2.1467e-7 | 3.3509e-10 |

`α(C=0.15)/α(C=2.55) = 1.4822133320`，即热扩散系数在干燥全程变化 **48.2%** (F71)。

**结论**：耦合在问题2–4 上是**必须保留的物理**（T→D 单项就有 7.55e-2 kg/kg，
α 变化 48.2%）；在问题1 上则**必须关闭**（否则 1.4 K / 0.138 kg/kg）。
