## 3. 按问题的文献使用方案

### Q1 预热平衡阶段（0–1800 s）
- **模型层**：一维径向双场抛物型方程组 + 对称/Robin 边界（本题 `model/problem1.md` 已定稿）。文献支撑：L05 的 Luikov 湿热耦合方程（同构母型）；L02 §2.1 演示耦合项与蒸发源项的完整写法（本题预热段近似无内部蒸发，可在假设论证中引 L02/L13 对比说明）；L07 用于论证"为何不引入压力场"。
- **数值层**：`src/q1_solve.py` 用守恒型有限体积 + Thomas + MOL/BDF 交叉验证；L05 提供同类方程有限体积离散的文献依据；L02（FEM/COMSOL）与 L13（COMSOL）作为"商业软件实现"的对照参照。
- **写作层**：解析解局限引 L06；中文行文与验证章结构参照 L13。
- **数据**：附件1 覆盖 0–14400 s（60 s 采样），Q1 时段插值无外推。

### Q2 全过程（两阶段，附录3 公式）
- 分段（预热平衡/恒温干燥）参数切换：L13 明确按"预热平衡 + 恒温干燥"两阶段组织模型与参数，是分段策略的中文参照。
- 变物性 D(C,T)：附录3 的 D 含 Arrhenius 温度项 exp(−3850/T)（Ea/R=3850 K，Ea≈32 kJ/mol，食品水分扩散典型值），同构佐证引 L12 §2（柱坐标变物性）与 L10（变输运性质）；D 随 C 下降的处理引 L11 §3（D(X) 拟合）。
- 输出：前 3 h 的表3/表4 直接由 Q1 求解器换参数延续积分（注意 ρ、cp、k、D 换为附录3 且随场变化 → 矩阵时变，需每步重组或用 MOL）。
- 两阶段工艺佐证：L16 的"快速干燥期/降速干燥期"划分与"快速期降温增风、降速期升温减风"规律，与题目"预热平衡 + 恒温干燥、两阶段参数不同"互证；L13 §六还给出"干区—湿区—蒸发区"迁移图像。

### Q3 烘干时长（C<0.15）
- 停机判据与干燥曲线：L09 §4 的 X(t)/X₀ 脱水曲线与"一维模型高估 Deff"的讨论（p4），L11 §3.2 干燥速率曲线；L12 §4 给出目标含水率时长的参数影响分析。
- 实现要点：时长由"中心（最干慢处）C<0.15"或"各处 C<0.15"定义（按题面"药材各处"→取 max_C<0.15），对总时长做事件定位（驻点求根），不需要逐步试扫。
- 数量级：附录3 在 50 °C、C=0.15 时 D≈8×10⁻¹⁰ m²/s → R²/D≈10⁵ s 量级，与 L09/L10/L11 实测 Deff（10⁻¹⁰~10⁻⁹）一致。外部对照：L16 中菊花 40/45/50/60/70 °C 达到烘干终点需 62/38/20/14/12 h，为本题数十小时量级提供工艺参照。

### Q4 收缩（附件2 + 附录4）
- **首选 L12**：与本题几何最同构（圆柱、径向、含收缩）；§3 的收缩映射（r₀δr₀→rδr，保证体积/质量守恒）与附录 p24 的离散细节可直接借鉴。
- **方法升级 L09**：把表面收缩处理为移动边界并并入热方程（非等温动边界），适合作为"本题动边界处理"的方法学引用。
- **数据对照 L11**：Table 1 实测收缩（30–50 °C，44–64%）与 Eq12–15 关联式（线性 L(X) 与幂律 L/L0~Vc）用于：① 验证附件2 R(t) 量级（前 1800 s 由 2.000→1.873 cm，约 6.3%；**全程 2.000→1.198 cm、收缩 40.1%**，与 L10/L12 报道的显著收缩量级一致）；② 论证本题取"径向收缩由附件2 插值、轴向不计（L/R=12.5）"的假设。
- **实现路线**（综述 §3.3/§6.4 有详细论证）：一维径向近等温场景优先 #11 半解析修正特征长度（R(C) 代入）或 #09 单参数移动边界（α₀≈0.83 由体收缩比反推）；坐标变换可用无量纲径向坐标 ξ=r/R(t) 把动边界化为固定域（引入附加对流项 −ξ(Ṙ/R)·∂C/∂ξ），与 #09 等价。
- 各向异性讨论：L10（若需论证"轴向收缩可忽略"或做敏感性）。

### L09 · 非等温动边界干燥模型（Q4 方法核心 / Q3 曲线）
- **地址**：`docs/09_CET_NonIsothermal_MovingBoundary_FoodDrying_2021.pdf`｜TXT 同名｜DOI 10.3303/CET2187033｜Brasiello, Venditti, Adrover, Chem. Eng. Trans. 87 (2021) 193–198
- **内容**：以**番石榴切片**为对象，在作者等温动边界模型（Adrover 2019b,c）基础上加入含蒸发与**表面收缩**的对流-扩散热方程，构成非等温动边界模型；§3 模型、§4 结果（间歇工况**零可调参数预测**成功）。
- **可提取**：① 单参数收缩方案：逐点收缩速度 $v_s=\alpha(c_w)\,\dfrac{D_{\rm eff}(T)}{\rho_w}\dfrac{\partial c_w}{\partial x}$、$\dot x_b=v_s|_{x_b}$，由体收缩比 V∞/V₀≈0.2 反推一维收缩因子 **α₀≈0.83**——本题 Q4 一维模型最实用的收缩方案；② D(T) 取 Arrhenius 形式；③ Table 2（p4）：Deff=1.557/2.877/9.258×10⁻¹⁰ m²/s（25/30/40 °C）；④ "一维模型倾向于高估有效扩散率"的讨论（p4）；⑤ "即使风温恒定也属非等温过程"的论断（热惯性与表面蒸发冷却）。
