## 五、检索过程备注（可复现性）

- OpenAlex 检索：`/works?search=<题名>`、`/works?filter=title.search:luikov`（55 条全量比对，用于定位 #5/#6/#7）
- Unpaywall：对全部 14 个 DOI 逐一核查 `is_oa` / `best_oa_location`（#1/#3/#6/#7/#8/#15/#14-starch1996 均 closed）
- PMC：ID Converter 确认 PMC7892935=Heliyon e06201、PMC7447739=JFST 菠萝片；PDF 经 Europe PMC `?pdf=render` 获取
- Semantic Scholar：无 API key，多次 HTTP 429（共享限流池），成功用于确认 CPINN 的 CC-BY 状态
- 失败可见性记录：SciELO 检索 API 有 Bunny Shield 人机验证（PDF 直链可下）；experts.illinois.edu（Pure）403；ResearchGate/Wiley/ScienceDirect 均有 Cloudflare 拦截；cn.bing.com 对中英文精确短语检索均返回无关结果
