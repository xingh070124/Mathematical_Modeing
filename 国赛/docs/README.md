# docs/ 目录导航

本目录存放赛题文本与文献资料。**智能体请从 `文献使用指南.md` 开始。**

| 文件/目录 | 说明 |
|---|---|
| `A题.md` / `A题.pdf`（在 `../A题/`） | 2026 国赛 A 题"药材的烘干问题"题面（md 为派生检索文本） |
| **`文献使用指南.md`** | 文献使用方法 + 地址索引（问题→文献→可提取内容，含 BibTeX） |
| `文献索引.csv` | 机器可读索引（15 条：DOI/OA/本地路径/对应问题/使用要点） |
| `文献清单_下载报告.md` | 文献检索与 OA 核查过程记录（来源可复现） |
| `文献综述.md` | 九篇全文文献深度综述：机理建模/收缩建模/工艺试验三范式、方法学横向对比、按问题借鉴要点 |
| `*.pdf` | 9 篇本地全文（L02/L05/L09/L10/L11/L12/L13/L16/L17） |
| `txt/` | 上述 PDF 的全文纯文本（带 `[page N]` 页码标记，可直接 `grep -n "关键词" docs/txt/*.txt`） |

检索入口示例：

```bash
# 按问题过滤文献
python -c "import csv;[print(r[0],r[9],r[11]) for r in csv.reader(open('docs/文献索引.csv',encoding='utf-8-sig')) if 'Q4' in r[9]]"
# 全文关键词定位（含页码）
grep -n "moving boundary" docs/txt/*.txt
```
