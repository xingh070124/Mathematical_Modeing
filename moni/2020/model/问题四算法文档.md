## 2. 对称性指标算法

### 2.1 关键时刻提取

```
def 峰值与穿越(t, T):
    t_pk  = t[T.argmax()]
    t_in  = 穿越时刻(t, T, 217, 方向=升)     # 升温侧
    t_out = 穿越时刻(t, T, 217, 方向=降)     # 降温侧
    return t_pk, t_in, t_out
```

> 若 $T_{\max}$ 出现平台（多个相等最大点），$t_{pk}$ 取最大值区间中点。

### 2.2 归一化时间对齐

将峰前、峰后各自归一化到 $\theta \in [0,1]$：

```
def 归一化曲线(t, T, t_pk, t_in, t_out):
    # 峰前: θ = (t - t_pk)/(t_pk - t_in),  θ∈[-1,0]
    # 峰后: θ = (t - t_pk)/(t_out - t_pk), θ∈[0,1]
    θ_grid = np.linspace(0, 1, 200)          # 公共采样网格
    T_pre  = np.interp(θ_grid, 归一化(峰前段), 峰前温度)
    T_post = np.interp(θ_grid, 归一化(峰后段), 峰后温度)
    return θ_grid, T_pre, T_post
```

> **归一化方向说明**：将峰前曲线沿时间轴翻转（$-θ$）后与峰后曲线比较，即以峰值时刻为对称轴做镜像。

### 2.3 对称性指标

L1 距离：

```
D(u) = np.trapezoid(np.abs(T_pre - T_post), θ_grid)
```

L2 距离：

```
D2(u) = np.sqrt(np.trapezoid((T_pre - T_post)**2, θ_grid))
```

辅助指标：

```
D_area = abs(峰前面积 I1 - 峰后面积 I2)
D_t    = abs((t_pk - t_in) - (t_out - t_pk))
```

### 2.4 归一化参考

```
D_ref = D(u_Q3)          # 问题三最优解对应的对称性指标
D_norm(u) = D(u) / D_ref
```

> 若 $D_{ref}$ 接近 0（问题三解几乎对称），改用基线工况计算 $D_{ref}$ 或直接使用未归一化 $D$。

## 3. 多目标目标函数

### 3.1 加权目标（主方案）

$$
F(\boldsymbol{u}; \lambda) = (1-\lambda)\,\frac{A(\boldsymbol{u})}{A^{*}_{Q3}} + \lambda\, D_{norm}(\boldsymbol{u})
$$

```
def 加权目标(u, λ):
    A_norm = area(u) / A_Q3_star
    D_norm = symmetry(u) / D_ref
    return (1-λ)*A_norm + λ*D_norm
```

### 3.2 ε-约束目标（Pareto 扫描）

```
def ε约束目标(u, ε):
    D = symmetry(u)
    if D_norm(u) > ε:  return 1e6          # 对称性不满足 → 重罚
    return area(u)
```

## 4. 优化求解

### 4.1 加权方案：差分进化 + 多起点 SLSQP

```
bounds = [(165,185),(185,205),(225,245),(245,265),(65,100)]

def solve_weighted(λ):
    # 全局
    de = differential_evolution(
        lambda u: 加权目标(u, λ),
        bounds, maxiter=200, popsize=50, seed=42, workers=-1)
    # 多起点局部精化（SLSQP 带制程约束，同问题三）
    u_best = 多起点SLSQP(de.x)
    return u_best
```

### 4.2 λ 的选取

- 取 $\lambda \in \{0.3, 0.4, 0.5\}$ 分别求解；
- 比较三组结果，选"对称性改善明显且面积劣化可接受"的一组作为最终解；
- 论文中报告 $\lambda$ 取值与理由。

## 7. 实现要点与常见坑

| 坑 | 解决方案 |
| --- | --- |
| 峰值平台导致 $t_{pk}$ 不稳 | 最大值区间取中点 |
| 峰前/峰后时长差异大，直接比较失真 | 必须归一化到 $[0,1]$ |
| $D_{ref}$ 过小导致 $D_{norm}$ 膨胀 | 改用基线工况参考或直接未归一化 |
| 对称性 vs 面积量纲差异 | 用 $A/A_{Q3}^*$ 与 $D/D_{ref}$ 归一化后加权 |
| ε-约束下无可行解 | ε 从松到紧扫描；对每个 ε 重启多次 |

---

## 8. 测试用例与验收标准

1. **指标正确**：$D=0$ 时峰前/峰后镜像完全重合（人工构造对称曲线自测）；
2. **约束满足**：$u^*$ 全部制程界限在界内；
3. **对称性改进**：$D(u^*) < D(u^*_{Q3})$；
4. **面积代价小**：$A(u^*)$ 与 $A^*_{Q3}$ 偏差在可接受范围；
5. **Pareto 完备**：前沿随 ε 单调（面积增大时对称性改善）；
6. **可复现**：固定种子结果一致。

import numpy as np
from scipy.optimize import differential_evolution, minimize

A_Q3_star = 950.0        # 问题三最优面积（占位，由问题三算法输出）
D_ref     = 60.0         # 问题三最优解对称指标（占位）

def symmetry(u):
    t, T = solve_curve(u)
    t_pk, t_in, t_out = peaks_and_crossings(t, T)
    if t_out <= t_pk or t_pk <= t_in:
        return 1e6       # 未形成完整 217℃ 区间
    th, T_pre, T_post = normalize_curves(t, T, t_pk, t_in, t_out)
    return np.trapezoid(np.abs(T_pre - T_post), th)

def weighted(u, lam):
    return (1-lam)*area(u)/A_Q3_star + lam*symmetry(u)/D_ref

def eps_objective(u, eps):
    d = symmetry(u)/D_ref
    return area(u) if d <= eps else 1e6

# 加权求解
u_w = differential_evolution(lambda u: weighted(u, 0.4), bounds,
                             maxiter=200, popsize=50, seed=42,
                             workers=-1).x
u_w = multistart_slsqp(u_w, lambda u: area(u) + 1e9*infeas(u))

# Pareto 扫描
eps_lo, eps_hi = min_d, max_d
for eps in np.linspace(eps_hi, eps_lo, 12):
    res = minimize(lambda u: eps_objective(u, eps), x0=u_Q3,
                   method='SLSQP', bounds=bounds, constraints=cons)

print('u* =', u_w, 'A* =', area(u_w), 'D* =', symmetry(u_w))
