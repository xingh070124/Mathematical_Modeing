### 2.2 读取与清洗规则

- 用 `pandas.read_excel('附件.xlsx')` 读取；
- 时间序列：$t_0=0,\ t_1=0.5,\dots$，步长 0.5 s，共 710 行；
- **起点处理**：实测在 $t=19$ s（$T=30.03$℃）处传感器开始工作，$t=0$ 处的首行为占位噪声（$T=1$℃），需剔除；
- 有效数据区间：$\tau \in [0,\ 354]$ s（以 30 ℃ 为记录零点），即 $t \in [19,\ 373]$ s。

### 2.3 时间约定（两种，实现时必须统一）

- **约定 A（推荐，物理一致）**：以焊接区域进入炉前区域入口为 $t=0$，$x=vt$，$T(0)=25$℃。附件数据需平移对齐：传感器零点 $\tau=0$ 对应炉内绝对时间 $t=t^*$。
- **约定 B（简化）**：以传感器开始工作（$T=30$℃）为时间零点，取 $x_0=0$、$T(0)=30$℃ 直接积分。

> 本算法文档默认采用**约定 A**，并给出求解 $t^*$ 的迭代过程。

## 3. 炉内空气温度分布 $T_a(x)$ 的构造算法

### 3.1 坐标定义

输入：

- 温区数 $n=11$，温区长 $L=30.5$ cm，间隙 $g=5$ cm，炉前/炉后 $P=25$ cm；
- 设定温度数组 `T_set[1..11]`（问题一：173,173,173,173,173,198,230,257,257,25,25）。

计算各温区起止坐标：

```
for i in 1..11:
    x_start[i] = P + (i-1)*(L+g)
    x_end[i]   = x_start[i] + L
```

### 3.2 分段函数 $T_a(x)$

构造函数 `Ta(x)`，输入 $x\in[0,\ X_{total}]$，输出环境温度：

```
Ta(x):
    # 炉前区域
    if 0 <= x < P:
        return interp(0→25℃, P→T_set[1])
    # 各小温区与间隙
    for i in 1..11:
        if x_start[i] <= x <= x_end[i]:
            return T_set[i]            # 温区内部：设定温度
        if i < 11 and x_end[i] < x < x_start[i+1]:
            return interp(x_end[i]→T_set[i], x_start[i+1]→T_set[i+1])  # 间隙线性过渡
    # 炉后区域
    if x_end[11] <= x <= x_end[11]+P:
        return interp(x_end[11]→T_set[11], x_end[11]+P→25℃)
```

其中 `interp(xA→TA, xB→TB)` 为线性插值：

$$T_a(x) = T_A + \frac{x-x_A}{x_B-x_A}(T_B-T_A)$$

### 3.3 可选改进：边界平滑

对温区边界附近 ±$\epsilon$ 区间（建议 $\epsilon = 2.5$ cm，即半个间隙），用 **Hermite 三次插值**（`scipy.interpolate.PchipInterpolator`）替代线性段，保证 $T_a(x)$ 及其一阶导数连续，数值积分更稳定。实现时：以全部关键点（炉前端点、各温区起止点、间隙中点、炉后端点）作为插值节点即可。

> **注意**：温区 10~11 设定为 25 ℃（不控制），其"温区内部温度"实为车间环境温度，构造 $T_a$ 时该段直接取 25 ℃ 即可。

## 4. ODE 数值求解算法

### 4.1 求解问题

$$\frac{dT}{dt} = \alpha\big(T_a(vt)-T\big), \qquad T(t_0)=T_0$$

问题一：$v = 78/60 = 1.3$ cm/s，$t_0=0$，$T_0=25$℃。

### 4.2 数值方法：经典四阶 Runge-Kutta（RK4）

时间步长 $\Delta t = 0.25$ s（内部分辨率，输出时重采样到 0.5 s）。

$$k_1 = f(t_n, T_n), \quad k_2 = f(t_n + \tfrac{\Delta t}{2},\ T_n + \tfrac{\Delta t}{2}k_1), \quad k_3 = f(t_n + \tfrac{\Delta t}{2},\ T_n + \tfrac{\Delta t}{2}k_2), \quad k_4 = f(t_n+\Delta t,\ T_n+\Delta t\,k_3)$$

$$T_{n+1} = T_n + \frac{\Delta t}{6}(k_1 + 2k_2 + 2k_3 + k_4)$$

其中 $f(t,T) = \alpha\big(T_a(vt)-T\big)$。

**端点值处理**：$T_a(x)$ 在温区边界处分段不光滑，但不连续点测度为零，RK4 仍收敛；如需更高精度，可在边界处采用自适应步长（`solve_ivp` 的 `rtol=1e-8, atol=1e-10`）。

### 4.3 求解区间

$$t \in [0,\ t_{end}], \qquad t_{end} = \frac{X_{total}+x_{0}}{v} + \Delta t_{cool}$$

其中 $\Delta t_{cool}$ 为离开炉后的冷却观察段（建议 60 s，使曲线完整显示降温）。

## 5. 参数标定算法（最小二乘）

### 5.1 目标函数

$$\min_{\alpha} J(\alpha) = \sum_{k} \Big(T_{model}(\tau_k;\alpha) - T_{obs}(\tau_k)\Big)^2$$

$\tau_k$ 为附件采样时刻（30 ℃ 起算，步长 0.5 s），$T_{obs}$ 为实测温度。

### 5.2 单参数标定流程

```
标定 α:
    v0 = 70/60                      # 附件工况速度
    T_set0 = [175×5, 195, 235, 255×2, 25×2]   # 附件工况温度
    构造 Ta0(x)

    f(α):                            # 目标函数
        # 约定 A：需同时求出 t*(α)
        t_star = 求解 T(t*)=30℃，从 T(0)=25℃ 用 RK4 积分
        T_model = RK4 求解 ODE，得到时刻序列 τ = t - t*
        与实测对齐（最近邻/插值到附件采样点）
        return Σ(T_model - T_obs)^2

    α* = minimize_scalar(f, bounds=[α_lo, α_hi], method='bounded')
    return α*
```

- 初始搜索区间：$\alpha \in [0.01,\ 0.5]\ \text{s}^{-1}$（经验范围）；
- 使用 `scipy.optimize.minimize_scalar` 或 `scipy.optimize.least_squares`；
- 收敛判据：相对步长 < $10^{-6}$。

### 5.3 分段换热系数标定（改进版）

将 $\alpha$ 分为升温段 $\alpha_1$（$T$ 上升阶段）与冷却段 $\alpha_2$（$T$ 下降阶段），两参数用二维网格搜索 + 局部优化：

```
标定(α1, α2):
    积分 ODE，当 dT/dt>0 用 α1，当 dT/dt<0 用 α2
    返回残差平方和
α1*, α2* = least_squares(F, x0=[0.1, 0.1])
```

> 峰值温度（$dT/dt=0$）处自动切换，无需人工判断。

### 5.4 拟合质量检验

- 计算决定系数：$R^2 = 1 - \frac{\sum(T_{obs}-T_{model})^2}{\sum(T_{obs}-\bar{T}_{obs})^2}$；
- 计算最大绝对误差 $\max |T_{obs}-T_{model}|$ 与均方根误差 RMSE；
- 绘制实测 vs 模型对比图（同图双曲线）。

## 8. Python 实现要点（关键代码骨架）

```python
import numpy as np
import pandas as pd
from scipy.optimize import minimize_scalar
from scipy.interpolate import PchipInterpolator
import matplotlib.pyplot as plt

# 参数
L, g, P, n = 30.5, 5.0, 25.0, 11
X_total = P + n*L + (n-1)*g + P   # 435.5

def build_Ta(T_set):
    """返回函数 Ta(x)，输入 x (cm)，输出环境温度 (℃)。"""
    xs = np.array([P + (i)*(L+g) for i in range(n)])       # 各温区起点
    xe = xs + L                                            # 各温区终点
    pts_x, pts_T = [0.0, P], [25.0, T_set[0]]
    for i in range(n):
        pts_x += [xs[i], xe[i]]; pts_T += [T_set[i], T_set[i]]
        if i < n-1:
            pts_x += [xe[i]+g/2, xs[i+1]]; pts_T += [(T_set[i]+T_set[i+1])/2]*1 + [T_set[i+1]]
    pts_x += [xe[-1]+g, xe[-1]+g+P]; pts_T += [T_set[-1]]*1 + [25.0]
    # 简化：用 PCHIP 平滑插值整条曲线（含温区内平台）
    interp = PchipInterpolator(np.array(pts_x), np.array(pts_T))
    return lambda x: float(interp(np.clip(x, 0, X_total)))

def rhs(t, T, v, alpha, Ta):
    x = v*t
    return alpha*(Ta(x) - T)

def rk4_step(f, t, T, dt):
    k1 = f(t, T); k2 = f(t+dt/2, T+dt/2*k1)
    k3 = f(t+dt/2, T+dt/2*k2); k4 = f(t+dt, T+dt*k3)
    return T + dt/6*(k1+2*k2+2*k3+k4)

def solve_T(v, alpha, Ta, t_end, T0=25.0, dt=0.25):
    n_steps = int(np.ceil(t_end/dt))
    ts = np.linspace(0, n_steps*dt, n_steps+1)
    Ts = np.empty_like(ts); Ts[0] = T0
    for k in range(n_steps):
        Ts[k+1] = rk4_step(lambda t,T: rhs(t,T,v,alpha,Ta), ts[k], Ts[k], dt)
    return ts, Ts

# 标定（附件工况）
data = pd.read_excel('附件.xlsx', header=None).to_numpy()
tau = data[:,0]; Tobs = data[:,1]
mask = Tobs >= 30                     # 剔除占位行，取传感器有效段
tau_ok, Tobs_ok = tau[mask], Tobs[mask]

def calibrate():
    Ta0 = build_Ta([175]*5+[195,235,255,255,25,25])
    v0 = 70/60
    def J(alpha):
        ts, Ts = solve_T(v0, alpha, Ta0, 420.0)
        # 找 T=30 时刻对齐
        i30 = np.argmin(np.abs(Ts-30))
        T_al = np.interp(tau_ok, ts - ts[i30], Ts)  # 对齐后插值到附件采样
        return np.sum((T_al - Tobs_ok)**2)
    res = minimize_scalar(J, bounds=(0.01, 0.5), method='bounded')
    return res.x

alpha_opt = calibrate()
print('α* =', alpha_opt)

# 问题一预测
Ta1 = build_Ta([173]*5+[198,230,257,257,25,25])
ts1, Ts1 = solve_T(1.3, alpha_opt, Ta1, 400.0)
# 关键位置温度
x_keys = [111.25, 217.75, 253.25, 304.00]
for xk in x_keys:
    tk = xk/1.3
    print(f'x={xk}: T = {np.interp(tk, ts1, Ts1):.2f} ℃')
# 输出 0.5s 序列
t_out = np.arange(0, 400.0, 0.5)
pd.DataFrame({'时间(s)': t_out, '温度(℃)': np.interp(t_out, ts1, Ts1)}).to_csv('result.csv', index=False)
```

> **注**：以上为骨架代码，正式实现时需处理约定 A 的 $x_0$ 与 $t^*$ 对齐、分段 $\alpha$ 优化、绘图标注等细节。

## 9. 数值稳定性与精度控制

| 项 | 取值/建议 |
| --- | --- |
| 积分步长 $\Delta t$ | 0.25 s（RK4 局部截断误差 $O(\Delta t^5)$，0.25 s 足够） |
| 输出步长 | 0.5 s（与题目要求一致） |
| 边界不连续处理 | PCHIP 平滑 $T_a(x)$ 或自适应步长 |
| 标定优化 | `minimize_scalar` (bounded)，容差 $10^{-6}$ |
| 对齐精度 | 关键位置温度用线性插值，误差 $<10^{-3}$ ℃ |
