# references/ — 写作 SKILL 的细节文件库

总索引在 `../SKILL.md`（瘦索引：骨架公式 + 写作顺序 + routing table + 提交前 checklist + quick card + 附录）。本目录是按主题拆分的 15 个细节文件，**按需 Read**——不要一次全 load。

## 加载规则

写作不是线性的，读 SKILL 也不该线性。每个写作阶段或具体困境，先看 `../SKILL.md` §1 routing 表，决定 Read 哪 1–2 个文件。例：

| 你正在做什么 | Read |
|---|---|
| 写 abstract | `03-abstract.md` |
| 写 Results 子节 | `05-results.md` + `../FIGURE-SKILL.md` |
| 自审稿 | `09-reviewer-protocol.md` + `13-antipatterns.md` |
| 选投哪个刊 | `14-journals.md` |
| 长期 taste 培养 | `15-taste-development.md` |

详细映射见 `../SKILL.md` §1.1。
