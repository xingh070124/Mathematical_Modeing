## 3. 炉温曲线求解（复用问题一求解器）

对给定 $v$（cm/s）：

```
求解 T(t):
    x(t) = v * t
    Ta(x) = 问题一 3.2 节构造的分段函数（T_set2）
    用 RK4 / solve_ivp 求解 dT/dt = α*(Ta(vt) - T), T(0)=25
    t ∈ [0, t_end]，t_end = X_total/v + Δt_cool
    X_total = 435.5 cm（炉内总长）
    Δt_cool ≈ 60 s（冷却观察段）
    返回 (t 序列, T 序列)，内部步长 dt=0.25s
```

---

## 4. 制程指标提取算法

### 4.1 峰值温度

```
T_pk = max(T)
```

### 4.2 上升斜率与下降斜率

由数值微分得到瞬时斜率序列：

```
dT_dt = np.diff(T) / np.diff(t)          # 中心/前向差分
# 上升段（dT/dt>0）
S_r = max(dT_dt[dT_dt > 1e-9])
# 下降段（dT/dt<0）
S_d = min(dT_dt[dT_dt < -1e-9])
```

> 为提高斜率精度，可用 5 点中心差分（`np.gradient`），避免噪声放大；必要时对升温段做局部三次样条后解析求导取最大。

### 4.3 150~190 ℃ 升温时间

```
Δ = 0
for 相邻点 (t_k, t_{k+1}):
    if 升温段 (dT/dt>0) 且 区间与 [150,190] 有交集:
        求交集长度（线性插值精确计算边界）
        Δ += 交集长度
```

精确算法：定位 $T=150$ 与 $T=190$ 在升温段内的两个穿越时刻 $t_{150}$、$t_{190}$（线性插值），则

$$\Delta t_{150\sim190} = t_{190} - t_{150}$$

（若升温段未完整穿越该区间，则该工况不可行，直接返回失败标记。）

### 4.4 大于 217 ℃ 的时间

```
# 找到 T 穿越 217 的所有点
穿越时刻 t_cross = { t : T(t) = 217 }（线性插值求根）
# 大于217的区间为穿越点交替围成，取温度>217 的区间总长
Δ >217 = Σ(区间长度)
```

由于炉温曲线先升后降，$T>217$ ℃ 通常构成**单一连续区间**（预热/冷却段低于 217），故 $\Delta t_{>217} = t_{exit} - t_{enter}$，其中 $t_{enter}$、$t_{exit}$ 分别为升温侧与降温侧穿越 217 ℃ 的时刻。

### 4.5 指标打包

```
def 计算指标(v, α*, T_set2):
    t, T = 求解炉温曲线(v, α*, T_set2)
    return {
        'T_pk':      max(T),
        'S_r':       ...,
        'S_d':       ...,
        'Δt_150_190': ...,
        'Δt_gt_217':  ...
    }
```

## 5. 可行性判定

对指标向量 $C$ 与界限表 $[C^{lo}, C^{hi}]$：

```
def 可行?(C):
    return (240 <= C.T_pk <= 250)
       and (0   <= C.S_r  <= 3)
       and (-3  <= C.S_d  <= 0)
       and (60  <= C.Δt_150_190 <= 120)
       and (40  <= C.Δt_gt_217  <= 90)
```

## 6. 最大速度搜索算法

### 6.1 第一步：等间距扫描定位可行域

```
v_grid = np.arange(65, 101, 1)              # cm/min，步长 1
for v in v_grid:
    C = 计算指标(v)
    记录 (v, C, 可行?)
输出：可行区间 [v_lo*, v_hi*]（粗范围）
```

### 6.2 第二步：确定活跃约束

在扫描结果中，对可行域右端点 $v_{hi}^{*}$ 附近检查各下限约束的裕量：

```
裕量_j(v) = C_j(v) - C_j^lo        # 针对下限约束
最紧约束 = argmin_j 裕量_j(v_hi*)
```

### 6.3 第三步：二分法精确求解 $v_{\max}$

对最紧约束对应的临界速度做二分：

```
v_lo = v_hi*                  # 可行端点
v_hi = min(100, v_hi* + 1)    # 不可行端点
while (v_hi - v_lo) > 1e-3:   # 精度 0.001 cm/min
    v_mid = (v_lo + v_hi) / 2
    if 可行?(v_mid):  v_lo = v_mid
    else:            v_hi = v_mid
v_max = v_lo
```

> **二分单调性前提**：需先验证"可行 ⇒ 速度更小也可行"（即约束关于 $v$ 单调）。机理上 $T_{pk}$、$\Delta t_{150\sim190}$、$\Delta t_{>217}$ 均随 $v$ 递减，满足单调性；若实现中发现非单调（如斜率指标在边界徘徊），改用**三分搜索**或**网格加密 + 局部扫描**，更稳妥。

### 6.4 第三步替代方案：直接约束求根

对最紧约束 $j^*$，直接解方程 $C_{j^*}(v) = C_{j^*}^{lo}$：

```
def g(v):  return C_{j*}(v) - C_{j*}^{lo}
v_max = brentq(g, v_lo, v_hi)     # scipy.optimize.brentq
```

其中 `brentq` 对单调函数稳定收敛，速度精度可达 $10^{-6}$。

## 9. 精度与稳健性控制

| 项 | 取值/建议 |
| --- | --- |
| 扫描步长 | 1 cm/min（粗定位） |
| 二分/求根精度 | $10^{-3}$~$10^{-6}$ cm/min |
| 穿越时刻插值 | 线性插值，误差 $<0.01$ s |
| 斜率精度 | 5 点差分或样条解析导数 |
| 单调性校验 | 若斜率指标出现非单调，改用三分法 |

## 10. 测试用例与验收标准

1. **单调性测试**：$T_{pk}$、$\Delta t_{>217}$、$\Delta t_{150\sim190}$ 随 $v$ 严格递减；
2. **可行性边界**：$v_{\max}$ 可行，$v_{\max}+0.5$ cm/min 不可行且越界指标恰为关键约束；
3. **交叉验证**：关键约束在 $v_{\max}$ 处裕量接近 0（$<0.1$ s 或 $<0.05$ ℃）；
4. **合理性**：$v_{\max} \in [65,100]$，且 $T_{pk}\in[240,250]$ 附近；
5. **可复现**：固定随机种子，重复运行一致。
