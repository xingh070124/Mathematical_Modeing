# model/ —— 数学模型

存放 2020A 炉温曲线问题的建模与算法文档。四个问题按"建模文档 + 算法文档"成对组织，复用同一机理模型（集总热容 + 牛顿冷却定律，参数由附件数据标定）。

## 文档清单

| 文档 | 内容 |
| --- | --- |
| `问题一建模文档.md` | 焊接区域温度变化规律模型：假设、Biot 数检验、热平衡方程、参数标定、关键位置计算 |
| `问题一算法文档.md` | 数据读取、T_a(x) 构造、RK4 求解、最小二乘标定、result.csv 输出、Python 骨架 |
| `问题二建模文档.md` | 最大允许过炉速度：制程界限约束、单变量优化模型、临界约束机理分析 |
| `问题二算法文档.md` | 制程指标提取、可行性判定、扫描+二分/brentq 求 v_max |
| `问题三建模文档.md` | 最小化 217℃~峰值面积：面积定义、5 维决策空间、罚函数约束优化模型 |
| `问题三算法文档.md` | 差分进化 + SLSQP 求解、面积精确计算、约束复核与敏感性分析 |
| `问题四建模文档.md` | 结合峰值对称性的双目标优化：对称性指标量化、多目标处理方法 |
| `问题四算法文档.md` | 归一化时间对齐、对称指标计算、加权/Pareto 前沿求解 |

## 建模逻辑主线

1. **问题一**：建立基础模型（ODE），用附件数据标定换热系数 α；
2. **问题二**：固定温度，优化速度（求 v_max）；
3. **问题三**：温度 + 速度联合优化，最小化面积；
4. **问题四**：在问题三基础上增加对称性目标，多目标折中。

所有数值实现（求解器、标定、优化）的代码骨架在对应算法文档中给出，正式代码建议放 `src/` 目录。
