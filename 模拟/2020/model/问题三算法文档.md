# 问题三 算法文档 —— 最小面积优化炉温曲线的数值实现

> 2020 年高教社杯全国大学生数学建模竞赛 A 题（炉温曲线）· 问题三
> 本文档给出问题三最小面积优化问题的完整算法，与《问题三建模文档》配套。核心链路：**5 维决策空间 → ODE 求解 → 面积与制程指标提取 → 全局+局部优化**。

## 2. 决策空间与编码

### 2.1 决策变量

$$\boldsymbol{u} = [T_{1\sim5},\ T_6,\ T_7,\ T_{8\sim9},\ v]$$

| 下标 | 变量 | 下界 | 上界 |
| --- | --- | --- | --- |
| 0 | $T_{1\sim5}$ | 165 | 185 |
| 1 | $T_6$ | 185 | 205 |
| 2 | $T_7$ | 225 | 245 |
| 3 | $T_{8\sim9}$ | 245 | 265 |
| 4 | $v$ | 65 | 100 |

### 2.2 解码

给定 $\boldsymbol{u}$，展开为 11 温区设定温度数组：

```
T_set = [u0]*5 + [u1, u2, u3, u3, 25, 25]
```

由 T_set 构造环境温度函数 $T_a(x)$（复用问题一 3.2 节）。

## 3. 目标函数 $A(\boldsymbol{u})$ 的数值计算

### 3.1 计算链路

```
def 面积(u):
    T_set = 解码(u)
    v_cm_s = u[4] / 60.0
    t, T = solve_curve(v_cm_s, alpha_opt, T_set)   # ODE 求解（复用问题一 RK4）
    if T.max() < 217:  return +inf                 # 未达回流温度，不可行
    A = 梯形积分(T-217, 区间{t: T>217}, 边界线性插值截断)
    return A
```

### 3.2 面积精确计算（边界插值截断）

1. 找 $T$ 穿越 217 ℃ 的时刻：升温侧 $t_{in}$、降温侧 $t_{out}$（线性插值求根）；
2. 将 $[t_{in}, t_{out}]$ 作为积分区间；
3. 在区间内用梯形法求 $\int (T-217)\,dt$：

```
def 梯形面积(t, T, t_in, t_out):
    # 在 [t_in, t_out] 上对 (T-217) 梯形积分
    ts  = np.concatenate(([t_in], t[(t>=t_in)&(t<=t_out)], [t_out]))
    Ts  = np.interp(ts, t, T)
    return np.trapezoid(Ts - 217, ts)
```

> 边界穿越点须用插值精确加入积分节点，否则面积低估（0.5 s 步长下误差约 1~2 ℃·s）。

### 3.3 数值精度

- 内部 ODE 步长 0.25 s；
- 面积输出精度：$10^{-2}$ ℃·s；
- 为去除数值噪声对优化的影响，面积函数本身光滑（除约束边界），差分进化可直接优化。

## 4. 约束处理

### 4.1 制程指标提取

```
def 制程指标(t, T):
    T_pk       = T.max()
    dTdt       = np.gradient(T, t)
    S_r        = dTdt[dTdt > 1e-9].max()
    S_d        = dTdt[dTdt < -1e-9].min()
    dt_150_190 = 升温段穿越(150,190)时间差      # 仅升温段
    dt_gt217   = t_exit(217) - t_enter(217)
    return {...}
```

### 4.2 罚函数目标

将制程界限转化为罚项：

$$
\tilde{A}(\boldsymbol{u}) = A(\boldsymbol{u}) + \rho \cdot \sum_{j} \big[ \max(0,\ g_j(\boldsymbol{u})) \big]^2
$$

其中规范化约束 $g_j$：

| 约束 | $g_j = $ |
| --- | --- |
| $T_{pk}\ge 240$ | $240 - T_{pk}$ |
| $T_{pk}\le 250$ | $T_{pk} - 250$ |
| $S_r \le 3$ | $S_r - 3$ |
| $S_d \ge -3$ | $-3 - S_d$ |
| $\Delta t_{150\sim190} \ge 60$ | $60 - \Delta t_{150\sim190}$ |
| $\Delta t_{150\sim190} \le 120$ | $\Delta t_{150\sim190} - 120$ |
| $\Delta t_{>217} \ge 40$ | $40 - \Delta t_{>217}$ |
| $\Delta t_{>217} \le 90$ | $\Delta t_{>217} - 90$ |

罚因子 $\rho$ 从 $10^3$ 起步，随优化迭代倍增到 $10^6$（保证可行解优先）。

> **边界可等号**：$g_j \le 0$ 视为可行（$\max(0,g_j)=0$），因此最优解允许峰值=240、$\Delta t_{>217}=40$ 等边界解。

## 5. 优化算法

### 5.1 全局优化：差分进化

```
bounds = [(165,185),(185,205),(225,245),(245,265),(65,100)]
result = differential_evolution(
    fun=罚函数, bounds=bounds,
    strategy='best1bin',
    maxiter=200, popsize=50,   # 50×5=250 初始种群
    tol=1e-7, seed=42,
    workers=-1                 # 并行
)
u_best = result.x
```

### 5.2 局部精化：SLSQP

以 `u_best` 为初值，用带边界与非线性约束的 `SLSQP` 精化：

```
from scipy.optimize import minimize
cons = [
    {'type':'ineq','fun':lambda u: 240 - 制程指标(u)['T_pk']},   # 峰值≥240
    {'type':'ineq','fun':lambda u: 制程指标(u)['T_pk'] - 250},
    {'type':'ineq','fun':lambda u: 3 - 制程指标(u)['S_r']},
    {'type':'ineq','fun':lambda u: 制程指标(u)['S_d'] + 3},
    {'type':'ineq','fun':lambda u: 制程指标(u)['dt_150_190'] - 60},
    {'type':'ineq','fun':lambda u: 120 - 制程指标(u)['dt_150_190']},
    {'type':'ineq','fun':lambda u: 制程指标(u)['dt_gt217'] - 40},
    {'type':'ineq','fun':lambda u: 90 - 制程指标(u)['dt_gt217']},
]
res = minimize(面积, x0=u_best, method='SLSQP',
               bounds=bounds, constraints=cons,
               options={'ftol':1e-10,'maxiter':500})
u_opt = res.x
```

> SLSQP 对非光滑目标可能早停，因此**多次以不同全局解为初值重启**（多起点），取面积最小且约束满足者。

### 5.3 计算预算

- 每次 ODE 求解 <0.1 s；
- DE 250 种群 × 200 代 ≈ 5 万次目标调用 ≈ 5000 s 单核；并行 8 核约 10 分钟；
- 可降低 `maxiter=100` 或先粗后细两阶段搜索以缩短时间。

### 6.2 局部最优性检查

- 多起点 SLSQP 结果一致性（最优解偏差 <0.1 ℃）；
- 对最优解做小幅扰动（±0.5 ℃ 或 ±1 cm/min），面积应增大或不变；
- 检查 KKT 型条件：至少一个约束活跃（通常峰值温度与 $>217$ ℃ 时间触及下界）。

## 8. 实现要点与常见坑

| 坑 | 解决方案 |
| --- | --- |
| `interp1d(T,t)` 对非单调 $T$ 报错 | 先拆分单调段再求穿越根 |
| 面积低估 | 边界穿越点插值加入积分节点 |
| 罚函数梯度噪声致 SLSQP 早停 | 多用差分进化结果做初值、多起点重启 |
| 不可行初始点 | 罚函数保证向可行域收敛；若始终不可行，放宽罚因子并检查界限表 |
| 优化时间过长 | 并行（`workers=-1`）、降低 `popsize/maxiter`、代理模型 |

---

## 9. 测试用例与验收标准

1. **功能正确**：最优解所有制程指标在界限内；
2. **目标改进**：$A^*$ 明显小于基线工况（实验设定 175/195/235/255，v=70）的面积；
3. **活跃约束**：至少峰值温度或 $\Delta t_{>217}$ 触及下界；
4. **稳健性**：不同随机种子/初值下最优解偏差 <0.5 ℃；
5. **可复现**：固定 `seed=42` 重复运行一致。

## 附录 D：参考实现框架

```python
import numpy as np
from scipy.optimize import differential_evolution, minimize

alpha_opt = 0.10            # 问题一标定值（占位）
bounds = [(165,185),(185,205),(225,245),(245,265),(65,100)]

def decode(u):
    return [u[0]]*5 + [u[1], u[2], u[3], u[3], 25.0, 25.0]

def solve_curve(u):
    T_set = decode(u)
    return rk4_solve(v=u[4]/60.0, alpha=alpha_opt, T_set=T_set)  # 返回 t,T

def area(u):
    t, T = solve_curve(u)
    if T.max() <= 217: return 1e9
    t_in, t_out = crossings(T, t, 217.0)
    return trapz_area(t, T, t_in, t_out)

def penalty(u):
    t, T = solve_curve(u)
    ind = indicators(t, T)
    g = violation_vector(ind)      # 各 g_j = max(0, ...)
    return area(u) + rho * np.sum(g**2)

# 阶段1：全局
de = differential_evolution(penalty, bounds, maxiter=150,
                            popsize=40, seed=42, workers=-1)
# 阶段2：多起点局部
u_best = min((minimize(area, x0=de.x + np.random.randn(5)*1e-2,
                       method='SLSQP', bounds=bounds,
                       constraints=cons).x
              for _ in range(20)), key=lambda u: area(u) + 1e9*infeas(u))
print('u* =', u_best, 'A* =', area(u_best))
```
