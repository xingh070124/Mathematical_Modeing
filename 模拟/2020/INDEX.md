# 2020年 模拟赛 —— A题 炉温曲线

## 项目简介
2020年高教社杯全国大学生数学建模竞赛 A 题，研究回焊炉中电路板焊接过程中的温度分布（炉温曲线），通过机理建模与制程界限优化，确定各温区设定温度与传送带过炉速度。

## 目录结构

| 目录/文件 | 说明 |
| --- | --- |
| `docs/` | 文档资料（题目解读、思路、参考文献等） |
| `model/` | 数学模型（公式推导、求解代码、说明文档） |
| `paper/` | 论文（LaTeX 源码与插图） |
| `src/` | 数据处理与求解程序 |
| `2020A-炉温曲线.docx` | 赛题原文 |
| `附件.xlsx` | 炉温曲线实测数据 |
| `result.csv` | 实验数据导出（时间,温度） |
