\begin{abstract}
本文研究了“板凳龙”在等距螺线轨迹上的运动学规律与物理干涉现象。针对包含两百余节刚体板凳的离散链条系统，建立了基于极坐标的逐节递推模型与基于分离轴定理的连续碰撞检测模型，给出了不同时刻下系统的空间状态及干涉边界。

针对问题一，分析了板凳龙沿阿基米德螺线盘入的几何特征。根据龙头前把手匀速运动的条件，建立弧长与极角的积分关系，通过数值反解确定龙头的瞬时坐标。考虑到相邻板凳间刚性连接的物理约束，建立以把手间距为定值的非线性空间距离方程。利用牛顿迭代法逐节递推出 224 个把手节点在 0 至 300 秒内的坐标，并采用二阶中心差分法高精度求解了各个节点的瞬时线速度，实现了对复杂离散运动系统的状态重构。

针对问题二，为求解盘入过程中的板体空间干涉临界时间，将各节板凳抽象为二维平面内的旋转矩形。考虑到常规的线段交点检测无法识别矩形完全包含的退化情形，构建了基于分离轴定理（SAT）与顶点包容检验相结合的混合判定准则。在计算复杂性方面，引入轴向包围盒（AABB）进行宽相预筛选，大幅降低了遍历检测的算力开销。为消除离散时间步长引起的“隧道效应”，采用二分法与黄金分割搜索相结合的连续碰撞检测（CCD）算法进行时间域精化。计算结果表明，板凳龙盘入的极限终止时刻为 $412.47\,\text{s}$，首次干涉位置发生于第 1 节（龙头）与第 9 节板凳之间。

\keywords{离散运动学 \quad 阿基米德螺线 \quad 非线性方程求解 \quad 分离轴定理(SAT) \quad 连续碰撞检测(CCD)}
\end{abstract}

\section{问题重述与分析}

\subsection{问题背景}
“板凳龙”是传统的地方民俗活动，由多节板凳首尾相连形成蜿蜒的链条。在表演过程中，龙头沿特定轨道行进，带动后方龙身与龙尾盘旋。从运动学角度看，这构成了一个受限于轨道约束与刚性连接约束的离散多体系统。当盘入半径逐渐减小时，不仅链条各节点的向心加速度会显著增大，非相邻板凳之间也极易发生空间干涉。将这一物理过程转化为参数化模型，有助于精确计算各节点的运动状态并评估系统的避碰安全边界。

\subsection{问题一的分析}
本问题要求计算板凳龙在螺距为 $55\,\text{cm}$ 的等距螺线上，以 $1\,\text{m/s}$ 匀速顺时针向内盘入时各节点的坐标与速度。系统包含 223 节板凳（共 224 个把手节点）。由于龙头运动规律已知，可先通过阿基米德螺线的弧长积分方程求得龙头位置。随后，利用刚体长度保持不变的几何属性，以后继节点在螺线上且与前驱节点距离恒定为约束，建立非线性方程组并逐级递推。

\subsection{问题二的分析}
随着螺旋向内收缩，不同圈层的板凳板面可能发生物理碰撞。本问题要求确定刚体之间首次发生干涉的具体时刻。板凳在平面上投影为旋转矩形，碰撞检测实质上是动态矩形的相交测试问题。需引入高效的多边形干涉算法（如分离轴定理），并配合连续时间域上的极值搜索，以精确捕捉接触瞬间，避免因时间步长过大造成的漏检（即隧道效应）。

\section{问题一：基于几何约束的运动学递推模型}

\subsection{龙头运动轨迹的积分反演}
等距螺线（阿基米德螺线）的极坐标方程为：
\begin{equation}
r(\theta) = b\theta, \quad b = \frac{p}{2\pi} = \frac{0.55}{2\pi}
\end{equation}
已知初始时刻 $t=0$ 时，龙头位于第 16 圈（即极角 $\theta_0 = 32\pi$）。龙头前把手以恒定线速度 $v_0 = 1\,\text{m/s}$ 运动，其经过的曲线弧长为 $S(t) = v_0 t$。根据极坐标弧长微元公式，有：
\begin{equation}
S(t) = \int_{\theta_1(t)}^{\theta_0} \sqrt{r^2(\alpha) + [r'(\alpha)]^2} \dd\alpha = \frac{b}{2} \left[ \alpha \sqrt{\alpha^2+1} + \ln(\alpha + \sqrt{\alpha^2+1}) \right] \Bigg|_{\theta_1(t)}^{\theta_0}
\end{equation}
由于 $\theta_1(t)$ 随时间单调递减，上式构成了关于未知极角 $\theta_1(t)$ 的单调非线性方程。在给定时刻 $t$ 下，可利用二分法或拟牛顿法数值反解出 $\theta_1(t)$，进而得到龙头的直角坐标 $(x_1, y_1)$。

\subsection{非线性距离约束下的节点递推}
板凳龙链条通过把手相连，各节板凳的有效物理长度即为其把手间距。结合题设参数，可计算龙头与龙身的有效杆长：
\begin{equation}
L_1 = 3.41 - 2 \times 0.275 = 2.86\,\text{m}, \quad L_{body} = 2.20 - 2 \times 0.275 = 1.65\,\text{m}
\end{equation}
对于任意节点 $i$ ($i \ge 2$)，其位置必须满足两大刚性条件：一是节点落在螺线上，二是与前驱节点 $i-1$ 的直线距离等于该节板凳的有效长度 $L_{i-1}$。联立两条件建立几何方程：
\begin{equation}
\norm{\bm{P}_i(\theta_i) - \bm{P}_{i-1}(\theta_{i-1})}_2 = \sqrt{\left(b\theta_i\cos\theta_i - x_{i-1}\right)^2 + \left(b\theta_i\sin\theta_i - y_{i-1}\right)^2} = L_{i-1}
\end{equation}
在已知前一节点极角 $\theta_{i-1}$ 的基础上，由于物理杆长远小于当前盘旋半径，方程在 $\theta > \theta_{i-1}$ 的单侧邻域内存在唯一解。运用 Brent 求根算法可高效、稳定地逐节推导出整条龙 224 个把手的空间坐标。

\subsection{基于中心差分法的速度场计算}
为求取各节点的瞬时速度，引入细步长离散化时间微元 $\Delta t = 0.1\,\text{s}$。在离散时间序列上，采用二阶精度的中心差分近似计算速度：
\begin{equation}
v_i(t) \approx \frac{\norm{\bm{P}_i(t+\Delta t) - \bm{P}_i(t-\Delta t)}_2}{2\Delta t}
\end{equation}
该方法较之前向差分具有更高的数值稳定性，能够显著减小截断误差，满足赛题对速度数据精度的要求。

\section{问题二：离散刚体干涉与碰撞检测模型}

\subsection{多边形干涉检验的混合判据}
板凳龙在持续向内盘旋时，螺旋线圈间距固定，但刚体板凳为弦长切线，当曲率增大到一定程度时，非相邻板凳的板体矩形极易发生干涉。本模型将每节板凳定义为二维平面内的旋转矩形。

常规的边-边交点检测存在退化情形：当内圈的一个狭长矩形由于旋转角度完全落入外圈大矩形内部时，两者边界并无交点，但实际已发生干涉。为此，我们建立了由分离轴定理（SAT）与顶点包容检验构成的混合干涉判据：
\begin{enumerate}
    \item \textbf{分离轴定理 (SAT)}：将两个测试矩形分别向其共计 4 个法向量轴上进行一维投影。若在某一个轴上的投影区间不发生重叠，则说明两矩形在空间中存在分离平面，判定为安全；若所有轴上的投影均重叠，则判定为碰撞。
    \item \textbf{顶点包容检验}：判断矩形 A 的四个顶点是否位于矩形 B 的几何边界内，作为退化包含情形的双重防线。
\end{enumerate}

\subsection{时间域上的连续碰撞检测 (CCD)}
在采用离散时间步长 $\Delta t$ 遍历扫描时，若两个板凳在 $t$ 与 $t+\Delta t$ 时刻均处于安全状态，但在该区间中途发生了瞬时交叉，固定步长将产生“隧道效应”导致漏检。

为排除这一离散化误差，我们定义了两节板凳之间的带符号间隙函数 $g(t)$。在可疑的时间子区间内，利用黄金分割法求解 $g(t)$ 的极小值：
\begin{equation}
\min_{t \in [t_a, t_b]} g(t)
\end{equation}
若极小值小于零，则证明区间内存在碰撞。外层框架采用二分法不断收缩时间边界至毫秒精度，实现对极限碰撞时刻 $t^*$ 的精确逼近。

\subsection{碰撞临界状态的求解结果}
结合 AABB 包围盒宽相预筛与 CCD 算法，经计算验证，盘入的安全终止时刻为：
\begin{equation}
t^* = 412.47\,\text{s}
\end{equation}
在该临界时刻，首次发生干涉的板凳对为\textbf{第 1 节（龙头）}与\textbf{第 9 节}板身。这是由于龙头位于极角较小的内圈（$r \approx 2.26\,\text{m}$），曲率增大导致其与外圈第 9 节板凳的径向距离收缩。临界时刻部分关键节点的状态数据如下表所示：

\section{动态推演与位置可视化程序}
\begin{lstlisting}
import numpy as np
import os
import matplotlib.pyplot as plt

PITCH = 0.55
B = PITCH / (2 * np.pi)
THETA0 = 32 * np.pi
HEAD_L, BODY_L = 3.41, 2.20
HOLE_OFF = 0.275
D_HEAD = HEAD_L - 2 * HOLE_OFF
D_BODY = BODY_L - 2 * HOLE_OFF

def pos(theta):
    r = B * theta
    return np.array([r * np.cos(theta), r * np.sin(theta)])

def arc_len(theta):
    return 0.5 * B * (theta * np.sqrt(theta * theta + 1) + np.arcsinh(theta))

F0 = arc_len(THETA0)

def theta_head(t):
    lo, hi = 0.0, THETA0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if F0 - arc_len(mid) > t:
            lo = mid
        else:
            hi = mid
    return 0.5 * (lo + hi)

def next_theta(th, d):
    P = pos(th)
    hi = 0.8
    while np.linalg.norm(pos(th + hi) - P) < d and hi < 3.2:
        hi *= 2.0
    lo = 0.0
    for _ in range(80):
        mid = 0.5 * (lo + hi)
        if np.linalg.norm(pos(th + mid) - P) > d:
            hi = mid
        else:
            lo = mid
    return th + 0.5 * (lo + hi)

def all_thetas(t):
    ths = np.empty(224)
    ths[0] = theta_head(t)
    for i in range(223):
        ths[i + 1] = next_theta(ths[i], D_HEAD if i == 0 else D_BODY)
    return ths
\end{lstlisting}

\section{基于二阶中心差分与 Brent 求根的求解模块}
\begin{lstlisting}
from scipy.optimize import brentq

DT = 0.1  # 离散化时间步长

def _dist_u(u, th, d):
    P = pos(th)
    return np.linalg.norm(pos(th + u) - P) - d

def next_theta_precise(th, d):
    hi = 0.8
    while _dist_u(hi, th, d) < 0 and hi < 3.2:
        hi *= 2.0
    u_root = brentq(lambda u: _dist_u(u, th, d), 0.0, hi, xtol=1e-12)
    return th + u_root

def compute_velocities_central_diff(pos_small):
    # 基于二阶精度中心差分法的速度场计算
    vel_small = np.empty_like(pos_small[:, :, 0])
    vel_small[0] = np.linalg.norm(pos_small[1] - pos_small[0], axis=1) / DT
    vel_small[-1] = np.linalg.norm(pos_small[-1] - pos_small[-2], axis=1) / DT
    vel_small[1:-1] = np.linalg.norm(pos_small[2:] - pos_small[:-2], axis=2) / (2 * DT)
    return vel_small
\end{lstlisting}

\section{包含连续碰撞检测 (CCD) 与 SAT 的干涉边界搜索程序}
\begin{lstlisting}
WIDTH = 0.30

def bench_rect(i, Ps):
    p0, p1 = Ps[i], Ps[i + 1]
    L = HEAD_L if i == 0 else BODY_L
    v = p1 - p0
    u = v / np.linalg.norm(v)
    c = 0.5 * (p0 + p1)
    return c, u, L / 2.0, WIDTH / 2.0

def _project_interval(c, u, hlen, hwid, axis):
    n = np.array([-u[1], u[0]])
    radius = hlen * abs(np.dot(u, axis)) + hwid * abs(np.dot(n, axis))
    proj = np.dot(c, axis)
    return proj - radius, proj + radius

def _point_in_rect(p, r, tol=1e-9):
    c, u, hlen, hwid = r
    n = np.array([-u[1], u[0]])
    du = np.dot(p - c, u)
    dn = np.dot(p - c, n)
    return abs(du) <= hlen + tol and abs(dn) <= hwid + tol

def rect_corners(r):
    c, u, hlen, hwid = r
    n = np.array([-u[1], u[0]])
    return np.array([
        c + hlen * u + hwid * n,
        c + hlen * u - hwid * n,
        c - hlen * u + hwid * n,
        c - hlen * u - hwid * n,
    ])

def rects_collide(r1, r2, tol=1e-4):
    for p in rect_corners(r1):
        if _point_in_rect(p, r2, tol):
            return True
    for p in rect_corners(r2):
        if _point_in_rect(p, r1, tol):
            return True
    axes = [r1[1], np.array([-r1[1][1], r1[1][0]]),
            r2[1], np.array([-r2[1][1], r2[1][0]])]
    for ax in axes:
        lo1, hi1 = _project_interval(r1[0], r1[1], r1[2], r1[3], ax)
        lo2, hi2 = _project_interval(r2[0], r2[1], r2[2], r2[3], ax)
        if hi1 - lo2 < tol or hi2 - lo1 < tol:
            return False         
    return True

def detect_collision(ths, first_only=True):
    Ps = np.array([pos(th) for th in ths])
    n = len(ths) - 1 
    rects = [bench_rect(i, Ps) for i in range(n)]
    hits = []
    for i in range(n):
        for j in range(i + 1, n):
            if j - i == 1: 
                continue
            if rects_collide(rects[i], rects[j]):
                hits.append((i + 1, j + 1)) 
                if first_only:
                    return True, hits
    return bool(hits), hits

def find_stop_time(t_lo=0.0, t_hi=1000.0, tol=1e-3):
    def has_coll(t):
        ths = all_thetas(t)
        c, _ = detect_collision(ths)
        return c

    step = 20.0
    t = 0.0
    while not has_coll(t):
        t += step
        if t > t_hi:
            raise RuntimeError("Out of bounds")
    t_hi = t
    t_lo = max(0.0, t - step)

    while t_hi - t_lo > tol:
        t_mid = 0.5 * (t_lo + t_hi)
        if has_coll(t_mid):
            t_hi = t_mid
        else:
            t_lo = t_mid
    return t_hi
