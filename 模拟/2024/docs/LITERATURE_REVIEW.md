## 1. 赛题背景与选题逻辑

**赛题概要**：一条由 223 节板凳首尾相连构成的"板凳龙"沿等距螺线（阿基米德螺线）盘入/盘出。龙头前把手速度恒为 1 m/s。共 5 问：

- **问题 1**：给定螺距 55 cm，从龙头位于螺线第 16 圈 A 点起，求 0–300 s 每秒整条龙（全部 224 个把手）的位置与速度；
- **问题 2**：求盘入的终止时刻（相邻板凳不发生碰撞）；
- **问题 3**：给定直径 9 m 的圆形调头空间，求最小螺距使龙头能盘入到调头空间边界；
- **问题 4**：给定由两段相切圆弧组成的 S 形调头曲线（前段半径为后段的 2 倍），问能否调整圆弧使调头曲线变短；
- **问题 5**：在问题 4 的路径上，求龙头最大行进速度，使所有把手速度不超过 2 m/s。

**选题逻辑**：板凳龙本质上是"牵引车 + N 节挂车"的**广义 N 拖车（N-trailer）运动学系统**——每一节板凳通过把手（铰链）连接，相邻板凳的相对转角由铰接点几何决定。因此文献选取围绕三大主题展开：

| 路径几何 / 连续曲率路径 | Q3、Q4 | E1（Lekkas）、E3（Reeds-Shepp） |

## 3. 主题一：铰接车辆 / 多节拖车运动学

### 3.1 C3：Tanaka, Hori, Wang《Multi-objective Control of a Vehicle with Triple Trailers》

**基本信息**：作者来自日本电气通信大学（The University of Electro-Communications）与杜克大学。38 页长文，属于 Takagi-Sugeno 模糊控制 + LMI 设计的经典应用研究（发表于 2000 年代初的 IEEE 模糊控制领域）。

**研究对象**：一辆带**三节挂车**的车辆在倒车工况下的稳定控制，目标是沿直线倒回且不出现"折刀（jack-knife）"现象。

**核心模型（离散时间铰接链运动学）**——这是对板凳龙最有价值的公式：

设 θ₀ 为车体航向角，θ₁,θ₂,θ₃ 为三节挂车航向角，定义**相邻节间相对角**：

```
θ01 = θ0 − θ1,  θ12 = θ1 − θ2,  θ23 = θ2 − θ3
```

其递推关系为：

```
θ0(t+1) = θ0(t) + (ν·Δt/ℓ)·tan(u(t))        （u 为转向角）
θ1(t+1) = θ1(t) + (ν·Δt/L)·sin(θ01)
θ2(t+1) = θ2(t) + (ν·Δt/L)·sin(θ12)
θ3(t+1) = θ3(t) + (ν·Δt/L)·sin(θ23)
```

其中 ν 为车速，L 为挂车长度。**关键结论**：相邻两节的相对角变化率正比于 `sin(相对角)`——这正是板凳龙中相邻板凳相对转角演化的基本关系。当相对角达到 ±90°（该文定义八个"折刀"位置）时，系统进入折叠失稳状态，对应板凳龙中相邻板凳发生**碰撞**的临界构型。

**设计方法**：用两规则 Takagi-Sugeno 模糊模型线性化非线性运动学（在 `p(t)≈0` 与 `p(t)≈π` 两个工作点分别取 A₁,B₁ / A₂,B₂），采用**平行分布补偿（PDC）** 设计反馈增益 F₁,F₂，将所有性能指标化为**线性矩阵不等式（LMI）**：

- 稳定性（公共正定矩阵 X 的二次稳定性）；
- 衰减率（GEVP 广义特征值最小化）；
- **输入约束**：转向角不饱和 ‖u(t)‖ ≤ μ；
- **输出约束**：相对角不超过阈值 ‖θ01‖≤λ₁, ‖θ12‖≤λ₂, ‖θ23‖≤λ₃ —— 即**显式避免折刀**；
- 干扰抑制（L₂ 增益 γ）。

并给出不依赖初值 x(0) 的 LMI 约束改进（已知初值范数上界 φ 时，`φ²I ≤ X` 即可保证 `xᵀ(0)X⁻¹x(0) ≤ 1`），以及仿真 + 实物实验验证。

**对板凳龙的启示**：
1. 板凳龙 = 223 节挂车链，相邻节相对角演化公式 `θ̇ᵢ = (v/L)sinθᵢ` 是 Q1 求解的核心运动学；
2. "折刀（jack-knife）"直接对应 Q2 的"板凳之间不发生碰撞"约束——可转化为对相邻相对角的界约束；
3. LMI 约束化的多目标设计思路，为"约束下求最大速度/最小螺距"这类带约束优化提供了形式化框架。

### 4.2 E1：Lekkas, Dahl, Breivik, Fossen《Continuous-Curvature Path Generation Using Fermat's Spiral》(2013)

**基本信息**：*Modeling, Identification and Control*, Vol. 34, No. 4, 2013, pp. 183–198。作者来自挪威科技大学（NTNU，包括著名的 Thor I. Fossen）。

**要解决的核心问题**：Dubins 路径由"直线 + 圆弧"组成，在直线与圆弧的衔接点处曲率不连续（G¹ 连续但非 G²），导致侧向加速度跳变。传统改进方案是回旋线（clothoid / 欧拉螺线），但回旋线坐标含 Fresnel 积分、无解析式、计算昂贵。

**核心贡献——费马螺线（Fermat's Spiral, FS）**：

```
极坐标：r = k·√θ            （阿基米德螺线族 n=2 的情形）
曲率：  κ(θ) = 12√θ·(3+4θ²) / (k·(1+4θ²)^(3/2))
```

关键性质：
1. **κ(0) = 0**：费马螺线在原点曲率为零，可与直线**无曲率跳变**地衔接（而圆弧与直线衔接点曲率突变）；
2. **参数方程极简单**（√θ 与三角函数的乘积），比 clothoid 的 Fresnel 积分便宜得多；
3. 弧长需用 Gaussian 超几何函数计算，但绝对收敛、域无限制；
4. **参数化奇异问题**：`p(θ) ~ k√θ` 在 θ=0 处 `dp/dθ` 奇异（参数速度为零），导致路径跟踪速度命令发散。作者提出换元 `u := √θ`（`0 ≤ u ≤ √θmax`），得到正则参数化：

```
p_FS(u) = [ x0 + k·u·cos(ρu²+χ0) ; y0 + k·u·sin(ρu²+χ0) ]
|d/du p_FS(u)| = k√2·√(1+4ρ²u⁴)  ≠ 0   （正则性保证）
```

从而 FS 既可用于路径跟随，也可用于路径跟踪。

**路径构造两种模式**（与 clothoid 类比）：
- **FS smoothing**：用两段镜像 FS 完全替代圆弧，实现"直线—FS 升曲率—FS 降曲率—直线"的连续曲率路径；
- **circular smoothing with FS transition**：直线—FS（0→1/R）—圆弧—FS（1/R→0）—直线，即"带 FS 过渡的圆弧平滑"，得到 Dubins-with-FS-transition 路径。

**对板凳龙的启示**：
- Q4 的 S 形调头曲线由两段相切圆弧构成，若要求"能否调整使曲线变短"并保持**曲率连续**（龙头速度 1 m/s 时曲率跳变会造成侧向加速度冲击），可引入 FS/clothoid 过渡段替代纯圆弧——FS 的解析简单性使其成为理想替代；
- Q3 最小螺距问题本质是螺线与半径 4.5 m 圆的几何相切/相切空间问题，FS 的"与直线/圆曲率连续衔接"性质可用于构造螺线—调头边界之间的过渡曲线；
- 文中关于曲率 κ、路径切向角 χ_p、路径光滑度（Cⁿ 参数连续 vs Gⁿ 几何连续）的定义，是论文写作中路径几何术语的规范参考。

## 5. 主题三：路径约束下的时间最优速度规划

### 5.1 F1：Verscheure, Demeulenaere, Swevers, De Schutter, Diehl《Practical Time-Optimal Trajectory Planning for Robots: a Convex Optimization Approach》

**基本信息**：*IEEE Transactions on Automatic Control*（2008/2009，K.U.Leuven OPTEC 团队，含 Moritz Diehl）。

**要解决的核心问题**：给定几何路径，在机器人动力学与执行器（力矩）约束下求沿该路径的**全局时间最优轨迹**。

**核心方法——非线性换元 + 凸化**：
以路径坐标 s（s∈[0,1]）描述几何，轨迹由 s(t) 决定。机器人动力学沿路径化为：

```
τ(s) = m(s)·s̈ + c(s)·ṡ² + g(s)
```

作非线性换元：

```
a(s) = s̈        （沿路径的加速度）
b(s) = ṡ²       （沿路径速度平方）
补充约束： b'(s) = 2·a(s)
```

于是时间最优问题化为**单微分状态 b(s) 的凸最优控制问题**：

```
min   T = ∫₀¹ 1/√b(s) ds
s.t.  τ(s) = m(s)a(s) + c(s)b(s) + g(s)
      b'(s) = 2a(s)
      b(s) ≥ 0
      τ̲(s) ≤ τ(s) ≤ τ̄(s)
```

目标函数 `1/√b(s)` 为凸，约束全部线性 → **凸问题，任意局部最优即全局最优**。用**直接转录（direct transcription）离散化**后，归结为**二阶锥规划（SOCP）**，可用成熟数值算法（如 CVX/SDPT3）求解。

**扩展能力**（凸性保持）：
- 目标函数扩展：时间—能量折中（`x²/y` 型凸函数）、力矩变化率积分（`|τ'(s)|`）等；
- 不等式约束扩展：关节速度限制（`(qᵢ'(s))²·b(s) ≤ q̇̄ᵢ²`）、执行器/位置约束等。

**对板凳龙的启示**：
- Q5"龙头最大速度使各把手速度 ≤ 2 m/s"是一个**沿路径的速度约束规划**问题：整条龙上任意把手的线速度是龙头沿路径速度的函数（由 N-trailer 运动学决定），可把"所有把手 ≤ 2 m/s"写成对 `b(s)=ṡ²` 的路径相关约束，再用 F1 的凸框架求**可行/最优**速度剖面；
- F1 的"单一路径坐标 + 凸 SOCP"范式，比逐点试凑更系统，且能给出全局最优性证明（论文加分项）；
- 其"至少一个执行器饱和"的 bang-bang 特性（速度切换曲线 switching curve）对应"龙头全程 1 m/s"与"把手 2 m/s 约束同时活跃"的临界状态。

### 5.2 F2：Artuñedo, Villagra, Godoy《Jerk-limited Time-optimal Speed Planning for Arbitrary Paths》

**基本信息**：西班牙 CSIC-UPM（Centre for Automation and Robotics, Arganda del Rey, Madrid）团队，发表于 *Journal of Intelligent & Robotic Systems*（2020/2021，文中模板年份 2020）。

**要解决的核心问题**：对任意（与路径图元无关的）给定路径，在速度、纵向加速度、**加加速度（jerk）**三方面约束下，求**类人、舒适、时间最优**的速度剖面。区别于大量仅约束加速度、或仅适用于特定路径图元的方法。

**方法——两阶段递进**：

**阶段一：加速度受限速度规划（Algorithm 1）**
1. **速度限制曲线（speed limit curve）**：考虑最大速度与最大横向加速度，用向心加速度公式：

```
v_SLC,i = min{ v_max , √(a_lat_max / |κ_i|) }
```

（κ_i 为路径点 i 的曲率）——曲率越大，允许速度越低；
2. 由限制曲线求初始速度 v、加速度 a；
3. **正向扫描**：限制最大正纵向加速度（超限则改写 v_{i+1}、a_{i+1}）；
4. **逆向扫描**：限制最大负纵向加速度；
5. **fallback 策略**：若初/末速度约束无法满足（如路径太短），以允许的最大减/加速度重新规划初/末段，保证速度剖面连续。

**阶段二：加加速度受限规划**
- 依据 Pontryagin 极大值原理，时间最优轨迹为 jerk 上的 **bang-bang** 结构（依次取最大/最小 jerk）；
- 在加速度受限剖面的基础上引入 jerk 约束，得到光滑（加加速度受限）且仍近时间最优的速度剖面；
- 声称**路径图元无关**（不依赖 clothoid/直线/圆弧，甚至不需要曲率，只要速度限制曲线已含横向加速度约束）、**无需插值与优化迭代**、计算高效、适合实时。

**对板凳龙的启示**：
- Q5 中"所有把手速度 ≤ 2 m/s"的物理实质是**横向/纵向加速度与曲率耦合的速度限制**；F2 的 `v_SLC = min{v_max, √(a_lat_max/|κ|)}` 公式可直接用于构造"沿路径曲率相关的允许龙头速度曲线"；
