## 1. 项目定位（一句话记忆）

这是 **2024 年全国大学生数学建模竞赛 A 题《"板凳龙"闹元宵》** 的模拟赛目录：
`模拟/2024/` 下存放赛题（`A题.pdf`）、参考文献（`docs/`）、结果文件（`论文/result1.xlsx`, `result2.xlsx`, `result4.xlsx`）。
当前会话的工作产出 = 对 `docs/` 的**文献综述 + AI 索引 + 本记忆文档**。

**一句话建模本质**：223 节板凳首尾相连 = 一条"广义 N 拖车（N-trailer）"铰接链，沿阿基米德螺线（等距螺线）盘入盘出。龙头前把手速度恒 1 m/s。

## 2. 赛题五问速记（含关键数字）

| 问 | 任务 | 关键给定 | 数学本质 |
|---|---|---|---|
| Q1 | 0–300 s 每秒整条龙 224 个把手的位置/速度 | 螺距 55 cm；龙头 1 m/s；起点为第 16 圈 A 点；龙头板长 341 cm、龙身/尾 220 cm、板宽 30 cm、孔径 5.5 cm、孔距板端 27.5 cm | 阿基米德螺线参数化 + 铰接链相对角递推 |
| Q2 | 盘入终止时刻（相邻板凳不碰撞） | 同 Q1 螺线 | 碰撞/折刀约束（相对角或几何干涉） |
| Q3 | 最小螺距使龙头盘入到调头空间边界 | 调头空间 = 半径 4.5 m 圆（直径 9 m） | 螺线—圆几何相切 |
| Q4 | S 形调头曲线可否缩短（保持相切） | 两段相切圆弧，前段半径 = 2 × 后段；调头空间同 Q3；龙头 1 m/s | 最短路径下界（Reeds-Shepp）+ 连续曲率过渡（FS/clothoid） |
| Q5 | 龙头最大速度使各把手 ≤ 2 m/s | 沿 Q4 路径；龙头速度恒定 | 路径坐标速度约束规划 |

**赛道数字备忘**：223 节 = 1 龙头 + 221 龙身 + 1 龙尾；把手数 = 龙头前把手(1) + 龙身 221 个前把手 + 龙尾前把手(1) + 龙尾后把手(1) = 224。

## 3. 关键术语表（中文赛题 ↔ 数学语言）

| 赛题术语 | 数学/建模对应 |
|---|---|
| 螺距 55 cm 的等距螺线 | 阿基米德螺线 `r = a + b·θ`，径向上相邻圈间距 = 螺距（b·2π = 螺距） |
| 把手中心 | 相邻板凳的铰接点（连接约束点）；建模中作为"节点/车轮轴"处理 |
| 盘入 / 盘出 | 沿螺线向中心收（顺时针）/ 向外放开（逆时针） |
| 调头空间 | 半径 4.5 m 的圆形禁区/缓冲区，盘入盘出之间在此换向 |
| 龙头前把手速度 | 全队唯一的速度激励源（1 m/s）；其余把手速度由运动学推导 |
| 板凳不碰撞 | 等价于相邻节相对角不超临界（折刀 jack-knife）或相邻板几何不干涉 |
| 折刀（jack-knife） | C3 中定义：相对角达 ±90° 的折叠临界构型 → 碰撞/失控 |

### 4.1 可用（已全文抽取，可信）

| 文献 | 一句话贡献 | 赛题用途 |
